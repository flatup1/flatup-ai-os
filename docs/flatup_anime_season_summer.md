# FLATUP アニメ EP4「夏、強くなろう」（夏・夏休み）

**テーマ**: 友だちと力を合わせて、楽しく強くなる  
**対象**: 子ども・親世代（夏休みを充実させたい全員）  
**時間**: 36 秒  
**CTA**: 「夏休み集中 free trial」

---

## ストーリー概要

夏祭りのようなジムの雰囲気の中、ツムとリクが力を合わせて練習する。  
楽しさと真剣さが混ざった夏の時間。  
メルティやマサキの応援の中で、友だち同士の絆が深まる。

---

## 感情曲線

```
① 祭りムード（ワクワク）→ ② 気合い（やる気）→ ③ チームプレー（協力）
→ ④ 先生の笑顔（認可）→ ⑤ 全員で練習（一体感）→ ⑥ ジャンプ（喜び）
→ ⑦ 絆が深まる（友情）→ ⑧ 夏、強くなった（達成）
```
