# FLATUP GYM アニメ — 他AIへの引き継ぎ書

**このファイルだけを渡せば、別のAI（Codex / Gemini / Cursor / Copilot など）が続きを作れる。**
Claude Code はリポジトリの `CLAUDE.md` を自動で読むので、この引き継ぎ書は主に**それ以外のツール向け**。

> ⚠️ この文書は**正本ではない。正本の場所を指す地図**である。
> 内容が正本と食い違ったら、**必ず正本が勝つ**。ここを書き写して増やさないこと。

---

## 1. これは何のプロジェクトか

千葉県成田市の格闘技ジム **FLATUP GYM** の広報アニメ。
シリーズ「**閉館後のFLATUP**」は、**道具の視点**で子どもの成長を見守る短編集。

第0話「今日のチャンピオン」（35秒・縦9:16）:
閉館後のジムで、グローブ・ミット・タイマーが毎晩「今日いちばん強くなった子」を選ぶ会議を開く。
選ばれたのは、いちばん強くパンチを打った子ではなく、**初めて母の手を離して一歩前へ出た女の子**だった。

**目的は映像技術の誇示ではない。**
子どもの小さな一歩を見た親が「うちの子も自分の力で歩き始めている」と感じ、
「このジムなら安心して任せられるかもしれない」と思うこと。それだけ。

## 3. 絶対に破ってはいけないこと

1. **既存作品名をプロンプトに書かない。** 狙う絵柄は有名CGアニメ映画の主役級の可愛さだが、
   作品名・スタジオ名は法務上の地雷。**その可愛さを作っている要素**（瞳と虹彩の大きさ・
   複数のハイライト・ほお染め・角のない丸み・サブサーフェス・リムライト）へ分解して書く。
   `npm run test:movie` が禁止ワードを機械的に弾く。
2. **タトゥーを描かない。** どのキャラにも。
3. **生成画像・動画に文字を入れない。** 字幕とロゴは編集で後入れする。
4. **実在人物に似せない。** ツム・母はオリジナル。参照写真に写る実在スタッフの顔を写し取らせない。
   （マサキだけは例外で、`assets/canon/` が本人の確定素材）
5. **キャラDNAのブロックは一字も変えない。** 変えるならコードと docs を**同時に**直す。
   これがキャラ固定の生命線。
6. **送信・投稿・公開は必ず人間（JIN）が行う。** AIが作るのは常に下書き。
7. **子どもを泣かせる演出をしない。** 涙を描かない。感動を押しつけない。

## 4. 作り方（4日 + 承認ゲート2つ）

```bash
npm install
npm run movie -- list        # 全ショット一覧
npm run movie -- edl         # 編集台本＋字幕(.srt)。APIもネットも不要
```

| 日 | コマンド | 出るもの | ゲート |
|---|---|---|---|
| Day 1 | `npm run movie -- refs` | 設定画12種 × 2枚 | |
| | `npm run movie:adopt -- refs` | 採用（対話で1枚選ぶ） | **★JIN承認①** |
| Day 2 | `npm run movie -- scenes` | シーン静止画12種 × 2枚 | |
| | `npm run movie:adopt -- scenes` | 採用 | **★JIN承認②** |
| Day 3 | `npm run movie -- edl` | 編集台本＋字幕。静止画だけで仮編集 | 無音で伝わるか |
| Day 4 | `npm run movie -- cuts` | 動画4カット（image-to-video） | |

**Mac はダブルクリックで全部できる** → `scripts/movie.command`

**順番を飛ばさないこと。** 採用（adopt）を飛ばすと、シーン生成に設定画が添付されず、
キャラの顔がカットごとに変わる。

`FAL_KEY` 未設定なら **DRY-RUN**（プロンプトの確認だけ・料金ゼロ）で動く。
まずこれで中身を確かめてから課金すること。

## 5. この設計で押さえている勘どころ

新しく入るAIが壊しやすい順に並べてある。

### 参照画像は「そのシーンに出るキャラの分だけ」添付する
全部添付すると、母の顔アップにグローブの設定画が付いて絵が濁る。
添付上限（6枚）で切るときは**キャラごとに1枚ずつ**確保する順に並べる。
素直に並べると Scene7（道具3体＋ツム＋母＝8枚）で**人間の参照が全部落ちる**。

### 字幕はカット割りから独立している
カットをまたいで良い。Scene1（0〜3秒）に置く字幕は23文字あり、
読める速度（毎秒7文字）だと3.4秒必要で、3秒には**物理的に入らない**ため。

### 字幕の下端は画面の62%（下から730px）
Instagram リールは **64〜82%に右のボタン列、88〜95%にアカウント名・曲名・キャプション**が乗る。
2つの帯の隙間は6%しかなく2行の字幕が入らないので、**ボタン列より上へ逃がすしかない**。
CapCut のセーフゾーン表示は Instagram のUIまで考えていない。信じないこと。

### 絵の構図は編集設計から自動で決まる
何秒映るか・字幕が乗るか・カメラが動くかで必要な絵は変わる。
`editPlan.composeClauses()` がプロンプトへ自動で足す。
**動画カットの構図要件は、その起点になる静止画に効かせる**（V2→C5c）。生成するのは静止画だから。

### 道具の質感を人間に掛けない
「ぬいぐるみのように／ずんぐりした手足」は道具4体だけ。
共通スタイルに入れると**母親の顔アップまでぬいぐるみになる**。

## 7. やってはいけない引き継ぎ方

- **正本を書き写して新しい「まとめ文書」を作らない。** 二重管理になり、
  どちらが正しいか分からなくなる。この引き継ぎ書も「地図」に徹している。
- **第0話が完成する前に、第2話以降の脚本を量産しない。**
  制作哲学は「AIでラクするな。AIで**何度も試せ**」。1本を作り切ってから増やす。
- **テストを消して回避しない。** テストは過去に実際に起きた事故の記録。
  落ちたら設計が間違っている。
