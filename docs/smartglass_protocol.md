# スマートグラス通信仕様（実装の正本）

このファイルが、`src/smartglass/protocol/` の言い分の出どころ。
**実機で確かめて違っていたら、コードとここを同時に直す。**

---

## 1. つなぐ（BLE）

```
スキャン ── サービス 7905FFF0-… または 6e40fff0-… を広告している機器
   ↓
接続 ── いちばん電波の強い1台（利用者に選ばせない）
   ↓
特性の割り当て ── write可＝command / notify可＝notify・data
   ↓
時刻合わせ（0x12）→ 電池（0x10）
```

### コマンドの形

```
 0    1        2        3 …            末尾
┌────┬────────┬────────┬──────────────┬──────────┐
│0xAB│オペコード│ 長さ   │ ペイロード    │チェックサム│
└────┴────────┴────────┴──────────────┴──────────┘
チェックサム = (オペコード + 長さ + ペイロードの総和) & 0xFF
```

壊れたフレーム・途中までのフレームは **捨てる（例外にしない）**。
BLEの通知は分割されて届くため。

### オペコード

| 値 | 名前 | 内容 |
|---|---|---|
| 0x01 | PHOTO | 写真を1枚 |
| 0x02 / 0x03 | VIDEO_START / STOP | 動画 |
| 0x04 / 0x05 | AUDIO_START / STOP | 録音 |
| 0x06 | AI_PHOTO | AI画像の生成 |
| 0x10 | BATTERY | 電池残量（応答: 先頭1バイトが％。101以上は「わからない」） |
| 0x11 | MEDIA_COUNT | メディア件数 |
| 0x12 | TIME_SYNC | 時刻合わせ（年下2桁,月,日,時,分,秒） |
| 0x20 | OPEN_WIFI_TRANSFER | 転送モード。応答: `SSID\0パスワード` |
| 0x21 | CLOSE_WIFI | 転送モードを終える |

> ⚠ オペコードの値はベンダーSDKに隠れている部分。
> 実機で確認できたら、この表と `frame.ts` の `OpCode` を同時に直す。
> フレームの形とチェックサムの計算は公開情報どおり。

## 2. 取り込む（Wi-Fi + HTTP）

```
① 0x20 を投げる          → SSID / パスワード（無ければ 123456789）
② その Wi-Fi に入る
     Android … Wi-Fi Direct（グラスがグループオーナー）
     iOS     … NEHotspotConfiguration(joinOnce)
③ IPをさがす             → 候補を同時に叩き、最初に返事をしたもの
     192.168.43.1 / 192.168.49.1 / 192.168.4.1 / 192.168.1.1 / 192.168.0.1 / 10.0.0.1
④ 一覧を読む             → /files/media.config → だめなら /manifest.json
⑤ 1件ずつ落とす          → /files/<filename>（Range で続きから）
⑥ Wi-Fiを抜けて 0x21     → 元のWi-Fiに戻す。メガネの電池を守る
```

### 一覧の2つの形

**A. media.config（テキスト）**
```
# コメント行は無視
IMG_20260825_101500.jpg,2400000
VID_20260824_183012.mp4 48000000
```

**B. manifest.json**
```json
{ "files": [ { "name": "IMG_20260825_101500.jpg", "size": 2400000, "time": 1756083300 } ] }
```

どちらも `parseManifest()` が `MediaItem[]` に揃える。
`time` は秒・ミリ秒・ISO文字列のどれでも読む。無ければファイル名の日時、
それも無ければ取り込んだ時刻を使う。

### 対象にするファイル
- 写真: jpg / jpeg / png / heic / heif / webp
- 動画: mp4 / mov / m4v / avi
- 音声: opus / wav / mp3 / m4a / aac / amr
- それ以外（`notes.txt` など）は**捨てる**。

## 3. 失敗したときの決まり

| 起きたこと | どうするか |
|---|---|
| 1件の取り込みが切れた | 受け取ったバイト数を覚え、`Range` で続きから。最大3回まで自動でやり直す |
| 3回だめだった | その1件は「あとで」に回し、**次のファイルへ進む** |
| 「あとで」が残った | ホームの主役ボタンが「取り込めなかったぶんを、もう一度取り込む」に変わる |
| Wi-Fiに入れない | 元のWi-Fiに戻し、「スマホのWi-Fiを入れてください」と案内する |
| どのIPも返事しない | 「メガネを近づけてください」と案内する |

**どの道すじでも、最後にかならず Wi-Fi を抜けて 0x21 を投げる**
（`try/finally`。途中で例外が出ても、メガネのWi-Fiは開けっぱなしにしない）。
