**結論**：言い返せない6歳の栄光くんが、FLATUPのキッズクラスで「ガード」と「心の技」を習い、保育園で、手を出さずに「それは、いやだ。かえして。」と言えるようになる話。全9ページ・38コマの縦読み。帰着点は**キッズクラスの体験の案内**。

- キャラの正本 → [../flatup_animation_bible.md](../flatup_animation_bible.md)
- 線引き → [manga_research/homage_guidelines.md](manga_research/homage_guidelines.md)

## 笑いどころと狙い（制作メモ）

| ページ | 仕掛け | ねらい |
|---|---|---|
| 1 | 劇画の巨大要塞 → 実はひざの高さの積み木 | 最初の3コマで笑わせて、読み進めてもらう |
| 2 | 「かえ……」で止まる | 内気な子の親が「うちの子と同じ」と思う |
| 3 | お迎えの大男 → 「おつかれさまでス！」 | 三人衆のカメオ。見た目が怖い人ほど優しい、というシリーズの約束 |
| 4 | 「成田保育園の覇者」の妄想 → 「そういう強さじゃない！」 | 保護者の「乱暴な子にならない？」という不安を、笑いにして否定する |
| 5〜6 | ガードは「自分を守って落ち着くため」。お芝居でミットを取る練習 | 体験の場面（基本フォーム＝ガード）を見せる。心の技とお芝居の練習は作中のイメージ（エンドカードに注記） |
| 6 | 「声が小さくても、言えたら100点！」、お姉さんのユイの助け舟 | 第2話の妄想の中の劇画コーチとは正反対の指導。FLATUPは怒鳴らない。年上の子が年下を助ける（バイブルの「仲間を応援」） |
| 6 | 「先生や大人に、たすけてと言おう」 | ヘルプサイン。言い返せない子に、逃げ道も用意する（保護者が安心する） |
| 7 | 心の中の巨大マサキ、ゴゴゴ、6歳の解説役 | ジョジョ風の誇張。いちばん盛り上がる場面 |
| 8 | 「かえしてくれて、ありがとう」「いっしょに、つかう？」 | 強さとは、優しさ。相手も悪者にしない。礼とありがとう（毎話の共通ルール） |
| 9 | 「なんでもない」と隠していた子が、自分から走ってきて話す | この話の中で完結する泣かせどころ。第2話を読んだ人には、さらに効く |
