# Web漫画 オムニバス第2話「成田へ、引っ越します。」ネーム

**結論**：成田への引っ越しを前に、心配性のママが夜中にネットで調べては、劇画の妄想をふくらませる話。言い返せない5歳の栄光くんを強くしたい。でも格闘技は怖い。その不安を笑いに変え、スマホで見たFLATUPの動画で「やってみたい」に変わる。全8ページ・34コマの縦読み。帰着点は**キッズクラスの体験の案内**。

- 動画版の絵コンテ → [hikkoshi_ep1_narita.md](hikkoshi_ep1_narita.md)（この漫画のコマから動画を作るときの設計。セリフはこの漫画版を正とする）
- 型と案内の正本 → [omnibus_series_bible.md](omnibus_series_bible.md)
- キャラの正本 → [../flatup_animation_bible.md](../flatup_animation_bible.md)
- 線引き → [manga_research/homage_guidelines.md](manga_research/homage_guidelines.md)

> ⚠️ **脚本の正本は、まだJINの決定待ち**（A：別のAIと作った指示書版／B：リポジトリ版）。この漫画版は、Claude のおすすめ案（Bを土台にして、「なんだコラ」「声が小せェ！」の2つのセリフを戻す）で作った。セリフは2つとも**ママの妄想の中だけ**で、言うのはちびキャラとシルエット。決定が変わったら、コマ19・20を差し替える。

## 作り方の約束

| 項目 | 決めごと |
|---|---|
| 形式 | スマホの縦スクロールのWeb漫画（1ページ＝縦長1枚、幅1080px）。コマは上から下へ。1コマに吹き出しが2つ以上あるときは右から左へ読む |
| 文字 | セリフは**縦書き**。画像AIに日本語を描かせない（吹き出しは空けて生成し、後から重ねる） |
| 絵柄 | 現実：温かい色のアニメ絵。ママの妄想：白黒の劇画（黒ベタ・集中線・スクリーントーン） |
| 吹き出し | 〇＝ふつう／⚡＝叫び（ギザギザ）／☁＝心の声（もこもこ）／▮＝劇画モノローグ（黒ベタに白抜き）／□＝ナレーション／♪＝小さい声 |
| 禁止 | 流血、痛がる顔、誰かが殴られる場面、怖い顔のアップ（妄想のコーチは必ずシルエット）、タトゥー、他社ロゴ、実在の店名、原作のセリフ・キャラ・技名 |

## 笑いどころと狙い（制作メモ）

| ページ | 仕掛け | ねらい |
|---|---|---|
| 1 | 「アルファード、多いって何？」 | 成田の人が「わかる」と笑う、地元ネタのつかみ |
| 2 | 劇画の成田 → 「チャイルドシート、ちゃんと付けてる」 | 成田を悪く言わずに、成田ネタで笑わせる。怖そうな人ほど家族思い |
| 3 | 「かえして」が言えない回想 | 内気な子の親が「うちの子と同じ」と思う（第3話で回収） |
| 5 | ケガ・乱暴・怖い先生・5歳でできる？の4連発 | 保護者の不安をすべて先に言葉にして、笑いで小さくする |
| 6 | 笑顔の子ども、誰も怒鳴らない、「ゆっくりでいいよ」 | 体験の場面（ミット打ち）を見せ、妄想と正反対の現実を見せる |
| 7 | 「見に行くだけ、行ってみる？」 | 見学のハードルを下げる橋渡し |
| 8 | 新しい家から見えるジムの灯り | タイトル「荒野に、灯り。」の世界観。エンドカードへ自然につなぐ |
