# 「ヒャッハー、体験に来る」（世紀末ナリタ伝説・三人衆の主役回）Web漫画ネーム＋60秒の縦動画台本（下書き）

**結論**：こわもての三人衆（黒田・黒川・黒木）が、はじめて FLATUP GYM の体験に来る話。いちばんこわもての黒田が、じつはいちばん緊張している。こっそり「初心者 ついていける」と検索し、ネットで見た「たのもォ！」を言ってしまい、腰のチェーンが扉の取っ手に引っかかって、前へつんのめる。マサキは半歩前に出て受け止め、マットにそっと座らせて「どこも、ぶつけてない？」。黒田は自分から大声を謝り、まっすぐのパンチで「パスン」と鳴らして、「来週も、来ていいスか」。**世紀末（202X年）は、AIのニュースを読みすぎた黒川の空想だけ**。町を語る大げさな言い方は**ネットの噂**として、同じコマで崩す。現実の三人は、予約して、くつをそろえて、安全運転で来る。Web漫画は全9ページ・27コマ。縦動画は60秒（劇画は18.5秒＝約31%）。閉じ方は、笑いのオチ（「声、出てる」「お迎え、行くぞ。」）と、黒川のノートPCの「202X年」が「来週も。」に書きかわる画面。**予約の案内はしない**（体験回ではないため）。

- 役割（仮）：認知・愛着（三人衆の主役回。12話中1〜2話の枠）。話数は12話の企画表（`series_12_plan.md`）で決める（JIN確認待ち。**ファイルは未作成。2026-10-30 時点**）。この話を体験回にするか、認知回のままにするかも、企画表でJINが決める（下の「未確認」）
