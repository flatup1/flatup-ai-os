# 「ヒャッハー、体験に来る」（世紀末ナリタ伝説・三人衆の主役回）Web漫画ネーム＋60秒の縦動画台本（下書き）

**結論**：こわもての三人衆（黒田・黒川・黒木）が、はじめて FLATUP GYM の体験に来る話。いちばんこわもての黒田が、じつはいちばん緊張している。夜にこっそり「初心者 ついていける」と検索し、ネットで調べた「たのもォ！」を言ってしまい、腰のチェーンが扉に引っかかる。マサキは半歩前に出て受け止め、「頭、打ってない？」。黒田は自分から大声を謝り、まっすぐのパンチで「パスン」と鳴らして、「来週も、来ていいスか」。**世紀末は、AIのニュースを読みすぎた黒川の頭の中と、ネットの噂の中だけ**。現実の三人は、予約して、くつをそろえて、安全運転で来る。Web漫画は全9ページ・27コマ。縦動画は60秒（劇画は19.5秒＝約3分の1）。閉じ方は笑いのオチと「来週も」。**予約の案内はしない**（体験回ではないため）。
