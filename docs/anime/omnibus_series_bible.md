## 1. 作り方

1. **Web漫画（縦読み）のネーム**で、話の流れ・セリフ・コマを設計する。セリフはネームを正とする（第1話だけは正本のA版が正）
2. ネームから、**30〜60秒の縦動画（9:16）**の台本を作る。秒数・映像・表情と動作・セリフと字幕・音・感情の変化を書く（マスタープロンプト §11 ⑤）
3. まず12話の企画表をそろえ、**代表作1話**で見た目・テンポ・工数を確かめてから、ほかの話を作る。12話を一度に映像生成しない。代表作の前に決めることと、その順番は §10 の「止めるもの」の列。**決まらないあいだの代わり**：姿の決まっていない人物（栄光・ママ・パパ・アイカ・三人衆）を、手元・後ろ姿・影・声だけで見せる「仮版」で、代表作のテンポと工数を先に測る（第1話の正本 §5 のアイカ、かえして回の黒田と同じやり方）。仮版は測るためのもので、公開するかはJINが決める
4. 文字は画像と別工程（吹き出しを空けて生成し、セリフや字幕は後から重ねる）
5. 無音でも意味が通じ、音があると感情が深まるようにする。複雑な格闘の動きより、表情・間合い・手元・小さな動き
6. 漫画の縦読みの約束：コマは上から下、1コマに吹き出しが2つ以上あるときは右から左。吹き出しは 〇ふつう／⚡叫び／☁心の声／▮劇画モノローグ／□ナレーション／♪小さい声
7. **ネームから秒数への目安**：動画にするコマに★を付ける。★1つは2〜6秒（ならすと3〜5秒）。60秒なら★は12〜20、30秒なら6〜10が目安。セリフのあるコマは「字数÷7」秒以上（字幕は1秒7字まで。置く文字・カードは1秒12字まで。`../emotional_movie_ep0_edit.md`）。★からこぼれたコマは、漫画だけに残す
8. **1話の絵柄は、温かい2Dの漫画絵・劇画の2種類まで**（#14 決定で3Dはやめた）。リアル劇画と劇画パロディは、墨の設定（太い輪郭線・黒ベタ・トーン・集中線）を共通にして、1種類と数える（第1話の別稿 v2 §4 と同じ）
9. 同じ話の漫画と動画で、人物の服・髪・小物を変えない
10. 動画のジムの中は**2Dの漫画絵**（#14 決定）。動画を「ネームの絵を動かす」か「別に2Dで生成する」かは、代表作で1カットずつ作って比べる

## 2. 世界と人物

- 舞台は成田と FLATUP GYM。シリーズの味は「親の想像は大げさ。現実は温かい。」「格好つけた直後に、生活感のある笑い。」「最後は、誰かの小さな優しさが残る。」
- **荒野と灯り**：荒野に見えるのは、ネットの噂とママの想像の中の成田。現実の成田には家々の灯りがたくさんあり、FLATUP GYM はそのひとつ。絵柄の切り替えで、町からジムに入ったことを見せるが、「町は暗い、灯りはジムだけ」と言い切るナレーションは書かない。町を語るナレーションは「……と、ネットに書いてあった」で崩す（崩しは同じコマ・同じ字幕・同じ大きさ。§6）。**例外：第1話 Scene 2**。正本（原文）のナレーション「成田——世界への玄関口（ゲートウェイ）。だが地元民（ジモティ）は誰ひとり飛び立たねェ……」は、同じ Scene の、別のカットのママの一言「……でも、チャイルドシートちゃんと付けてる。」で崩している。正本は書き換えないので、この決まりの例外とする。正本のまま使うときも、別稿 v2 を使うときも、Instagram・X・カルーセルでは**このナレーションだけを切り出さず、必ずチャイルドシートの一言までを1本（1つの投稿）に入れる**。別稿 v2 は、ママの声「……と、ネットに書いてあった。」を言い切りの最後の行と同じ字幕に足している（足した言葉なので【JIN確認】）
- **202X年、AIで世紀末**（JINの要望。OPと三人衆の回で使う）：中身は【案・§10 #17】「AIが便利になりすぎて、みんな座りっぱなし」。**AIを敵や、人の仕事を奪うものとして描かない**（ジムは「文武両道 × 最先端AI」〈`src/data/canon_2026.md` §2〉、AIトレーナーのアンディがいる〈バイブル〉）。できる・できないで人を分ける言い方（「体を動かせる人が、いちばんかっこいい」など）も使わない（世紀末回の下書きの直しに合わせた）
  - **だれの想像か**：世紀末の場面は、毎回、**最初のコマで「だれの頭の中か」を絵で見せる**（点線のもこもこの枠、その人の顔に当たるスマホやPCの光）。前後を現実のコマではさみ、現実の場面のナレーションには使わない。今の下書き（OP・世紀末回）は、どちらも**黒川の空想**（AIのニュースの読みすぎ。提案の設定）にそろえてある。ママの妄想は「ネットで見た成田」で、世紀末とは別のもの（第1話の笑いを先に使わないため）。持ち主を変える話を作るときは、§5-4 の「世紀末の持ち主」の行で確かめる
  - **「202X年、〜」の語り出しと「ヒャッハー」**：どちらも特定の作品を強く思い出させるので、**手引き §5 のレベルB と同じ扱い**にする。社内の呼び名・下書きでは使ってよい。公開版の画面・音声に使う前にJINが確かめる（§10 #4）。**表紙の見出しと、投稿文の1行目には使わない**。作品名は宣伝に書かない（手引き §2）
- ジムの3原則：**怒鳴らない・比べない・置いていかない**（バイブル）

## 3. 教育理念（マスタープロンプト §3 の要約）

- 強さとは、優しさ・自制・尊重・責任を**行動**にできること
- 子どもに無理に「練習しろ」と言わない。自分から「やってみたい」と思えるように関わる
- 挑戦したこと、できたこと、誰かを気づかったことを、**具体的に**ほめる。叱るときは、人格ではなく行動に向き合う
- やりたくなければ、やらなくていい。ただし、頑張っている人のじゃまはさせない（自由と境界を両方描く）
- 格闘技に通えば必ず性格が直る、とは描かない。小さな変化、時間、個人差、できる日とできない日を描く

**実話からの取り出し方**：マスタープロンプト §4 の3つの実話（息子の選択／5歳の娘への接し方／双子の成長）は、**価値観だけ**を取り出して新しい物語にする。既存キャラの家族や経歴に移さない。実在会員の証言として扱わない。人物が特定できる情報を入れない。**実話の属性（双子、小学4年生から家族になった、5歳の娘、など）は、どのキャラにも付けない**。「何も言わず横に立つ」のような行動は、属性のちがう別の子の行動として描き、誰が誰を慰めたかは断定しない。

## 4. 1話の作り方（固定の型はない）

**毎回同じ「問題 → 先生の説教 → 感動」にしない。**

| 組み替えるもの | 選択肢 |
|---|---|
| 視点 | 子ども／親／指導者／きょうだい／仲間／町の住人（三人衆）。※栄光くんに、きょうだいの設定はない。作るなら企画表に【提案】と書き、JINが採用してから使う。それまでは、ほかの家庭のきょうだいで描く |
| 葛藤 | 挑戦・比較・順番・失敗・見栄・嫉妬・休む・頼る・応援・待つ |
| 場所 | 家庭・送迎・入口・練習・試合・帰り道・町。※試合（UIZIN〈初陣〉をふくむ）は、結果・判定・相手を倒す場面を映さない。出番の前（待つ）と後（横に立つ・応援）だけ。UIZINの運営ルールは `canon_2026.md` §6 で未確定なので、ルールの中身は描かない |
| 主な感情 | 笑い・安心・驚き・悔しさ・誇らしさ・温かさ |
| 結末 | 笑いのオチ／静かな行動／親の気づき／次への期待 |

- **3つのレンズ**：Story（誰が、何を望み、何につまずき、何を選ぶか。変わることは1つでよい）／Psychology（保護者の心配・期待・焦り・後悔・誇らしさ。子どもの悔しさ・見てほしい気持ち・見栄・迷い）／Worldview（勝つ・強く打つ以外の格好よさ：待つ・謝る・頼る・断る・応援する・譲る・もう一度やる）
- **主な視聴者は、子どもの保護者**（マスタープロンプト §5）。昭和生まれ・平成初期生まれの親に届く劇画の熱量や懐かしさを使うが、世代で価値観を決めつけない（「昭和の親は〜」と笑わない）。元ネタを知らなくても楽しめるようにする（§9 の点検）
- **話を動かすのは**、子ども自身の選択、仲間の振る舞い、親の気づき。先生の説明で解決させない
- **最後に教訓を読み上げない**。映像で伝わることを、セリフやナレーションで重ねて説明しない。泣く・抱きしめる・感動的な音楽に頼らず、仕草と間で感情を作る
- **先生のキャッチコピー**（バイブルの「一歩ずつ…」「大丈夫。ゆっくりでいいよ。」「強くなる前に…」など）は、1話1回まで。話の締めの一言には使わない（第1話A版は正本なので例外）
- **笑いの対象**：大人の考えすぎ、格好つけと現実の落差、親子の認識のずれ、小さな出来事を大事件にする想像力。**笑いの対象にしない**：子どもの恐怖や感情の爆発そのもの、苦手なこと、家庭環境、外見、親の切実な悩み（失業・お金・病気などもふくむ）
- **笑いのエンジン**（各話で「主なエンジン」を1つ選び、企画表の「笑い」の列に番号を書く。笑うのは、いつも大人の側のずれ）

  | # | エンジン | 笑うところ | 笑わないところ |
  |---|---|---|---|
  | 1 | パパの格好つけと生活感の落差 | キメた直後の生活感（エコバッグ、寝ぐせ、ゆるい部屋着など） | パパの心配の中身 |
  | 2 | 三人衆の自己演出（ごっこ）と、礼儀正しい現実の落差 | 大げさなポーズと、小さな声・そろえたくつ | 見た目・家庭の事情・仕事 |
  | 3 | 大人の考えすぎ（先生・三人衆・ほかの保護者もふくむ） | 小さなことを大事件のように準備しすぎる | 子どもの失敗そのもの |
  | 4 | 親子の受け取り方のずれ | 大人の受け取り違い（子どもは正しいことを言っている） | 子どもの言い間違い・できなさ |
  | 5 | ママの妄想（劇画パロディ） | 妄想の飛躍だけ | ママの心配の中身（§2） |

  同じエンジンは**12話中3話まで、2話続けない**（ママの妄想は §5-2 の「3話まで」と同じ）。静かな回（笑いで始めない回）も、小さな笑いを入れるならエンジンの番号を書く。どれにも当たらない笑いを作るときは、上の「笑いの対象にしない」に入っていないかを先に確かめる
- **冒頭の1〜3秒**で、人物・状況・気になることが分かる。各話に3方向のフック（A：親子のあるある／B：意外性と笑い／C：意味を知りたくなる行動や表情）を、映像・短い字幕・音のセットで作る。フックの疑問は本編で回収する
- **次への期待**（認知回・指導への信頼回の閉じ方）：画面に「次回予告」は入れなくてよい。最後の1〜2秒を、**無音でも分かる「続きを感じる仕草か小物」**にする（例：かえして回の下書きの、奥でポーズをまねするハカセくん）。または第1話のように題名で終える。次の話の題名は投稿文に書く
- **シリーズをまたぐ目印**（話をまたいで「次も見たい」を作るため）
  - **栄光くんの「今」を、冒頭3秒のうちに小物で見せる**：オムニバスで、どの話から見られても分かるようにする。入会の前か後か、5歳か6歳かが、セリフなしで分かる小物を1つ決める【提案。JINが採用するまで設定台帳に入れない】。例：入会の前は保育園の通園かばんだけ／入会の後は、それにジムの小さなバッグが加わる。企画表に別の案（カレンダーの〇など）があれば、そちらと1つにまとめる
  - **12話のどこかに毎回出る、小さなくり返し**を1つ決める【提案】（例：家のどこかに、成長の印が一瞬映る）。決まったら §5-4 の表に行を足して数える
  - 投稿のつなぎ方（Xで前の話につなぐ、Instagramのピン留め）は §10 #18 の案で、JINに聞く
- **重複を防ぐ**：直近の話と、葛藤・見せ場・結末が同じにならないか、§5-4 の表で確かめる。人物名だけ変えた同じ話を作らない
