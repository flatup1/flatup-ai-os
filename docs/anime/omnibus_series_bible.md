## 0. 作り方（全話共通）

1. **まずWeb漫画（縦読み）のネームを作る**。ファイル名は `manga_epNN_<名前>.md`。セリフはこの漫画版を正とする
2. コマの絵を作る（吹き出しは空けて生成し、縦書きのセリフを後から重ねる）
3. 動画にするときは、漫画のコマを使って動かす（モーションコミック）。動画用の絵コンテ（`hikkoshi_ep1_narita.md` など）は、そのための設計として残す
4. 縦読みの約束：1ページ＝縦長1枚（幅1080px）、コマは上から下、1コマに吹き出しが2つ以上あるときは右から左。吹き出しの種類は 〇ふつう／⚡叫び／☁心の声／▮劇画モノローグ／□ナレーション／♪小さい声

## 1. 世界の設定（全話共通）

- 舞台は成田。202X年、AIが仕事を覚えた世紀末（……と、ネットに書いてあった）。
- 荒野の中に、ひとつだけ灯りがともる場所がある。それが FLAT UP GYM。
- ジムの3原則：**怒鳴らない・比べない・置いていかない**（バイブル）。
- 共通の出演者：マサキ（キック）、メルティ（ストレッチ・女性・キッズ）、アイカ（オーナー。姿の正本ができるまでは声だけ）、アンディ（AIトレーナー）、ミイチ（柔術）、ヒトシ（MMA）。
- **カメオ（ちょい役）**：ヒャッハー三人衆（黒田・黒川・黒木）は、どの話にも背景のどこかに1回だけ映る。ファンが探す楽しみになる。

## 2. 1話の型（全話この順番）

| 拍 | 割合の目安 | 中身 | 例（世紀末ナリタ伝説 第1話） |
|---|---|---|---|
| ① つかみ | 0〜15% | 劇画・世紀末・ジョジョ風などのパロディで、一気に引き込む | 202X年のナレーション |
| ② 主人公の不安 | 15〜30% | 見る人と同じ不安を、主人公に言わせる | 「腕立て0回なんスけど」 |
| ③ 妄想と誤解の爆発 | 30〜45% | 不安を大げさな妄想にして笑わせ、すぐ素に戻す | 道場破り → 自分のチェーンでこける |
| ④ 体験の1場面 | 45〜80% | **本物の体験30分の流れ**（下の表）から1場面を見せ、小さな成功を描く | ミットが「パスン」と鳴る |
| ⑤ やさしい強さの一言 | 80〜88% | その話のテーマを、1行の格言で残す | 殴られるより、優しくされるほうが効く |
| ⑥ 灯りのエンドカード | 88〜100% | 体験への案内（§4）。主人公の「次はあなたの番」につながる橋渡しのセリフから入る | 「来週も、来ていいスか」→ エンドカード |

**体験30分の流れ**（`src/data/trial_flow.md`）と、話ごとの担当場面：

| 体験の場面 | 見せると伝わること |
|---|---|
| 1. 受付・ごあいさつ | 笑顔で迎えてくれる。はじめてでも浮かない |
| 2. 準備・ストレッチ | 体がかたくても大丈夫。ケガをさせない |
| 3. 基本フォーム | 構え・ガード・ステップから、ていねいに教わる |
| 4. ミット打ち | コーチが受けてくれる。必ずほめてもらえる。達成感 |
| 5. サンドバッグ | 自分のペースでいい。ストレス発散 |
| 6. クールダウン・ご案内 | 質問できる。無理に入会をすすめられない |

> 1シーズンで、6つの場面がひととおり登場するように話を組む。全部見ると「体験で何をするか」が分かる。

### 4-3. エンドカードでやってはいけないこと
- 「今すぐ」「限定」「残りわずか」など、急がせる言葉（`brand_voice.md`：押し売りしない）
- `canon.ts` にない料金・割引・キャンペーン
- 全クラスの名前を並べること（`brand_voice.md`：最大2クラスに絞る）
- 「必ず強くなる」「1か月で変わる」などの約束
- 「世界一」を事実のように使うこと（あくまでブランドの理念として、ブランドラインの位置にだけ置く）
