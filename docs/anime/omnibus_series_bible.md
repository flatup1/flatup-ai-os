## 1. 作り方

1. **Web漫画（縦読み）のネーム**で、話の流れ・セリフ・コマを設計する。セリフはネームを正とする（第1話だけは正本のA版が正）
2. ネームから、**30〜60秒の縦動画（9:16）**の台本を作る。秒数・映像・表情と動作・セリフと字幕・音・感情の変化を書く（マスタープロンプト §11 ⑤）
3. まず12話の企画表をそろえ、**代表作1話**で見た目・テンポ・工数を確かめてから、ほかの話を作る。12話を一度に映像生成しない
4. 文字は画像と別工程（吹き出しを空けて生成し、セリフや字幕は後から重ねる）
5. 無音でも意味が通じ、音があると感情が深まるようにする。複雑な格闘の動きより、表情・間合い・手元・小さな動き
6. 漫画の縦読みの約束：コマは上から下、1コマに吹き出しが2つ以上あるときは右から左。吹き出しは 〇ふつう／⚡叫び／☁心の声／▮劇画モノローグ／□ナレーション／♪小さい声
7. **ネームから秒数への目安**：動画にするコマに★を付ける。★1つは2〜6秒（ならすと3〜5秒）。60秒なら★は12〜20、30秒なら6〜10が目安。セリフのあるコマは「字数÷7」秒以上（字幕は1秒7字まで。置く文字・カードは1秒12字まで。`../emotional_movie_ep0_edit.md`）。★からこぼれたコマは、漫画だけに残す
8. **1話の絵柄は3種類まで**（温かい2D・劇画・温かい3D）。リアル劇画と劇画パロディは、墨の設定（太い輪郭線・黒ベタ・トーン・集中線）を共通にして、1種類と数える（第1話の別稿 v2 §4 と同じ）
9. 同じ話の漫画と動画で、人物の服・髪・小物を変えない
10. 動画をネームの絵を動かして作るか、2D・3Dで別に作るか、動画のジムの中を3Dにするか2Dにするかは【未決定 §10 #14】。代表作で1カットずつ作って比べる

## 3. 教育理念（マスタープロンプト §3 の要約）

- 強さとは、優しさ・自制・尊重・責任を**行動**にできること
- 子どもに無理に「練習しろ」と言わない。自分から「やってみたい」と思えるように関わる
- 挑戦したこと、できたこと、誰かを気づかったことを、**具体的に**ほめる。叱るときは、人格ではなく行動に向き合う
- やりたくなければ、やらなくていい。ただし、頑張っている人のじゃまはさせない（自由と境界を両方描く）
- 格闘技に通えば必ず性格が直る、とは描かない。小さな変化、時間、個人差、できる日とできない日を描く

**実話からの取り出し方**：マスタープロンプト §4 の3つの実話（息子の選択／5歳の娘への接し方／双子の成長）は、**価値観だけ**を取り出して新しい物語にする。既存キャラの家族や経歴に移さない。実在会員の証言として扱わない。人物が特定できる情報を入れない。**実話の属性（双子、小学4年生から家族になった、5歳の娘、など）は、どのキャラにも付けない**。「何も言わず横に立つ」のような行動は、属性のちがう別の子の行動として描き、誰が誰を慰めたかは断定しない。

## 4. 1話の作り方（固定の型はない）

**毎回同じ「問題 → 先生の説教 → 感動」にしない。**

| 組み替えるもの | 選択肢 |
|---|---|
| 視点 | 子ども／親／指導者／きょうだい／仲間／町の住人（三人衆）。※栄光くんに、きょうだいの設定はない。作るなら企画表に【提案】と書き、JINが採用してから使う。それまでは、ほかの家庭のきょうだいで描く |
| 葛藤 | 挑戦・比較・順番・失敗・見栄・嫉妬・休む・頼る・応援・待つ |
| 場所 | 家庭・送迎・入口・練習・試合・帰り道・町。※試合（UIZIN〈初陣〉をふくむ）は、結果・判定・相手を倒す場面を映さない。出番の前（待つ）と後（横に立つ・応援）だけ。UIZINの運営ルールは `canon_2026.md` §6 で未確定なので、ルールの中身は描かない |
| 主な感情 | 笑い・安心・驚き・悔しさ・誇らしさ・温かさ |
| 結末 | 笑いのオチ／静かな行動／親の気づき／次への期待 |

- **3つのレンズ**：Story（誰が、何を望み、何につまずき、何を選ぶか。変わることは1つでよい）／Psychology（保護者の心配・期待・焦り・後悔・誇らしさ。子どもの悔しさ・見てほしい気持ち・見栄・迷い）／Worldview（勝つ・強く打つ以外の格好よさ：待つ・謝る・頼る・断る・応援する・譲る・もう一度やる）
- **話を動かすのは**、子ども自身の選択、仲間の振る舞い、親の気づき。先生の説明で解決させない
- **最後に教訓を読み上げない**。映像で伝わることを、セリフやナレーションで重ねて説明しない。泣く・抱きしめる・感動的な音楽に頼らず、仕草と間で感情を作る
- **先生のキャッチコピー**（バイブルの「一歩ずつ…」「大丈夫。ゆっくりでいいよ。」「強くなる前に…」など）は、1話1回まで。話の締めの一言には使わない（第1話A版は正本なので例外）
- **笑いの対象**：大人の考えすぎ、格好つけと現実の落差、親子の認識のずれ、小さな出来事を大事件にする想像力。**笑いの対象にしない**：子どもの恐怖や感情の爆発そのもの、苦手なこと、家庭環境、外見、親の切実な悩み（失業・お金・病気などもふくむ）
- **冒頭の1〜3秒**で、人物・状況・気になることが分かる。各話に3方向のフック（A：親子のあるある／B：意外性と笑い／C：意味を知りたくなる行動や表情）を、映像・短い字幕・音のセットで作る。フックの疑問は本編で回収する
- **次への期待**（認知回・指導への信頼回の閉じ方）：画面に「次回予告」は入れなくてよい。最後の1〜2秒を、**無音でも分かる「続きを感じる仕草か小物」**にする（例：かえして回の下書きの、奥でポーズをまねするハカセくん）。または第1話のように題名で終える。次の話の題名は投稿文に書く
- **重複を防ぐ**：直近の話と、葛藤・見せ場・結末が同じにならないか、§5-4 の表で確かめる。人物名だけ変えた同じ話を作らない
