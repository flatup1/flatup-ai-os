## 1. 作り方

1. **Web漫画（縦読み）のネーム**で、話の流れ・セリフ・コマを設計する。セリフはネームを正とする（第1話だけは正本のA版が正）
2. ネームから、**30〜60秒の縦動画（9:16）**の台本を作る。秒数・映像・表情と動作・セリフと字幕・音・感情の変化を書く（マスタープロンプト §11 ⑤）
3. まず12話の企画表をそろえ、**代表作1話**で見た目・テンポ・工数を確かめてから、ほかの話を作る。12話を一度に映像生成しない
4. 文字は画像と別工程（吹き出しを空けて生成し、セリフや字幕は後から重ねる）
5. 無音でも意味が通じ、音があると感情が深まるようにする。複雑な格闘の動きより、表情・間合い・手元・小さな動き
6. 漫画の縦読みの約束：コマは上から下、1コマに吹き出しが2つ以上あるときは右から左。吹き出しは 〇ふつう／⚡叫び／☁心の声／▮劇画モノローグ／□ナレーション／♪小さい声

## 3. 教育理念（マスタープロンプト §3 の要約）

- 強さとは、優しさ・自制・尊重・責任を**行動**にできること
- 子どもに無理に「練習しろ」と言わない。自分から「やってみたい」と思えるように関わる
- 挑戦したこと、できたこと、誰かを気づかったことを、**具体的に**ほめる。叱るときは、人格ではなく行動に向き合う
- やりたくなければ、やらなくていい。ただし、頑張っている人のじゃまはさせない（自由と境界を両方描く）
- 格闘技に通えば必ず性格が直る、とは描かない。小さな変化、時間、個人差、できる日とできない日を描く

**実話からの取り出し方**：マスタープロンプト §4 の3つの実話（息子の選択／5歳の娘への接し方／双子の成長）は、**価値観だけ**を取り出して新しい物語にする。既存キャラの家族や経歴に移さない。実在会員の証言として扱わない。人物が特定できる情報を入れない。

## 4. 1話の作り方（固定の型はない）

**毎回同じ「問題 → 先生の説教 → 感動」にしない。**

| 組み替えるもの | 選択肢 |
|---|---|
| 視点 | 子ども／親／指導者／きょうだい／仲間／町の住人（三人衆） |
| 葛藤 | 挑戦・比較・順番・失敗・見栄・嫉妬・休む・頼る・応援・待つ |
| 場所 | 家庭・送迎・入口・練習・試合・帰り道・町 |
| 主な感情 | 笑い・安心・驚き・悔しさ・誇らしさ・温かさ |
| 結末 | 笑いのオチ／静かな行動／親の気づき／次への期待 |

- **3つのレンズ**：Story（誰が、何を望み、何につまずき、何を選ぶか。変わることは1つでよい）／Psychology（保護者の心配・期待・焦り・後悔・誇らしさ。子どもの悔しさ・見てほしい気持ち・見栄・迷い）／Worldview（勝つ・強く打つ以外の格好よさ：待つ・謝る・頼る・断る・応援する・譲る・もう一度やる）
- **話を動かすのは**、子ども自身の選択、仲間の振る舞い、親の気づき。先生の説明で解決させない
- **最後に教訓を読み上げない**。映像で伝わることを、セリフやナレーションで重ねて説明しない。泣く・抱きしめる・感動的な音楽に頼らず、仕草と間で感情を作る
- **笑いの対象**：大人の考えすぎ、格好つけと現実の落差、親子の認識のずれ、小さな出来事を大事件にする想像力。**笑いの対象にしない**：子どもの恐怖や感情の爆発そのもの、苦手なこと、家庭環境、外見、親の切実な悩み
- **冒頭の1〜3秒**で、人物・状況・気になることが分かる。各話に3方向のフック（A：親子のあるある／B：意外性と笑い／C：意味を知りたくなる行動や表情）を、映像・短い字幕・音のセットで作る。フックの疑問は本編で回収する
- **重複を防ぐ**：直近の話と、葛藤・見せ場・結末が同じにならないか確かめる。人物名だけ変えた同じ話を作らない

## 8. 採点と検証（マスタープロンプト §12）

| 項目 | 配点 |
|---|---|
| 原作と人物の一貫性 | 20 |
| 親子への共感と尊厳 | 20 |
| フックと視聴継続 | 15 |
| 笑いと行動で伝わる優しさ | 20 |
| 各話の独自性とシリーズへの貢献 | 15 |
| 制作可能性と媒体展開 | 10 |

**点検**：原作を知る人が違和感を持たないか／元ネタを知らない保護者にも伝わるか／その子の失敗を笑いものにしていないか／先生の説明を削っても理念が伝わるか／前の話と同じオチになっていないか／冒頭の期待を本編が回収しているか／無音・スマホの実寸でも分かるか／指定の尺で、セリフと感情を味わう間が収まるか／確認していない事実を加えていないか。

点数だけを上げない。問題・直し方・確かめ方を具体的に書く。未確認の項目があれば満点にしない。公開後は、再生数に加えて、視聴継続・シェア・保存・プロフィール遷移・フォロー・続編への反応を媒体ごとに見る。体験回は、案内のクリック・予約・来店も見る。
