## 調査の制限（正直に書いておくこと）

- 調査した環境では、Webページを直接開く機能が使えなかった（ネットワーク設定で、Wikipedia・出版社サイトなどが許可されていなかった）。そのため、事実はすべて**Web検索の結果の要約**から取っている。
- 「確認済み」も「出版社のURLが検索結果に出た」ことが根拠で、ページ本文は読んでいない。厳しく見るなら、すべて二次情報扱い。
- X（旧Twitter）は直接検索していない。「ネットの評判」の列には、どの行にも「X直接検索なし」と書いてある。
- 本文を読めなかった作品は、心理描写・演出・ギャグの列の一部が「未確認」になっている。
- 連載中の作品の巻数は、調査した時点の数字。

## 調べてわかった、依頼の前提との違い

- 特攻の拓 After Decade の作画は、所十三ではなく桑原真也
- くろアゲハの掲載誌は、週刊ではなく月刊少年マガジン
- Let'sダチ公は、週刊少年チャンピオン（秋田書店）の作品
- 爆音列島は、高橋ツトムの作品（アフタヌーン）
- 「花沢三兄弟」という外伝は見つからなかった（ゼットンの本名が花澤三郎なので、その混同と思われる）
- クローズの正統続編として「ダストランド」（2026年）がある
- 「小説 ゆうえんち」は漫画ではなく小説の公式外伝。参考として1行入れてある
