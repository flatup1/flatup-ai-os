# ヤンキー・格闘技漫画のオマージュ手引き（FLATUP用）

**結論**：真似するのは「技法」（構図・間・誇張・テンポ）だけ。キャラ・セリフ・コマ・ロゴは真似しない。作品の芯は「不良漫画は好き。でも不良は嫌い。」「強さとは、優しさであり、かっこよさである。」「世界一、初心者に優しい格闘技ジム。」

- 研究データ → [works_database.csv](works_database.csv)（Excel版：`works_database.xlsx`）
- キャラと世界観の正本 → [../../flatup_animation_bible.md](../../flatup_animation_bible.md)（この手引きと食い違ったら、正本が勝つ）

## 1. 「○○風にして」と言われたときの変換ルール

作品名で指定されたら、その作品の**一般的な演出の特徴**に置き換えて作る。下の表の「モード」を使う。

| モード | よく指定される作品の例 | 使ってよい技法 |
|---|---|---|
| **劇画ヤンキー** | 特攻の拓、カメレオン、BADBOYS | 黒ベタを強く、太い輪郭線、荒いハッチング、極端なローアングル、激しい集中線、当て字ルビの大げさな独白、最後に一言で崩すギャグ |
| **青春不良コメディ** | 湘南純愛組!、今日から俺は!!、ゴリラーマン | 明るい青春の空気、キザな表情、不器用な優しさ、シリアスに始めて脱力でオトす、誇張と日常の落差 |
| **群像・矜持** | クローズ、WORST、ろくでなしBLUES | 仲間との並びの構図、無口な背中、短く言い切るセリフ、夕焼けや屋上などの「間」、筋を通す人物。絵柄はリアル劇画（§7） |
| **強面の先生** | ゼットン先生、GTO | 見た目は怖いのに一番まともなことを言う。話を最後まで聞く。怒鳴らず静かに正す。説教くさくせず、少し笑える一言で伝える |
| **武道・格闘技** | はじめの一歩、刃牙、ホーリーランド、修羅の門 | 正確な構えと体の使い方、力の伝わり方の図解、緊張した視線、努力の積み重ね、礼で始まり礼で終わる |
| **武術の修行** | 鉄拳チンミ、史上最強の弟子ケンイチ | 師匠と弟子の関係、小さな課題を1つずつクリア、弱い子が工夫で勝つ、修行のコミカルな描写 |
| **世紀末** | 北斗の拳 | 「202X年」から始まる重いナレーション、荒野と砂嵐、逆光のシルエット、間抜けな雑魚の叫び（くわしくは `../opening_seikimatsu_narita.md`） |
| **奇妙な冒険** | ジョジョの奇妙な冒険 | 背景いっぱいの擬音の文字、体を大きくひねったキメポーズ、芝居がかった言い切り、何が起きたかを大げさに説明する解説役、「部」ごとに主人公が替わる継承の構成（くわしくは §5） |

**変換の例**：「クローズ風の画像」→ 群像・矜持モード。オリジナルの制服やジャージ姿のFLATUPキャラを、横一列でローアングルから撮る。背景は夕焼けのジム前。校章・チーム名・特定キャラの髪型は使わない。

## 2. してはいけないこと

| 禁止 | 理由・代わりにすること |
|---|---|
| 原作のセリフ・名ゼリフ・決めゼリフを使う | 著作権。言い回しの**リズム**だけ借りて、言葉はオリジナルで作る |
| 特定のコマ・表紙・ポスターの構図を再現する | 著作権。構図の「型」（ローアングル、背中越しなど）は一般的な技法なのでOK |
| 原作キャラの髪型・顔・衣装・刺しゅう・チーム名・校名 | 著作権・商標。FLATUP独自のデザインにする |
| 作者名や作品名を、宣伝の画像や動画に書く | 公認と誤解される。作品名は社内の指示でだけ使う |
| 流血、痛がる顔、相手を倒して喜ぶ | バイブルの禁止事項。ギャグの「ドンッ」で済ませる |
| 反社会的な行動や暴走行為への憧れ | 作品の思想（不良は嫌い）と逆。不良は「勘違い」「妄想」「更生する側」として描く |
| 子どもを怖がらせる指導者 | FLATUPは怒鳴らない。怖い指導者は「妄想の中だけ」で、すぐ崩す |
| タトゥー、他社ロゴ | バイブルの禁止事項 |

## 3. オリジナル名言の作り方

**型**：「（ヤンキーっぽい言い切り）＋（優しさへのひっくり返し）」。少しキザで、少し笑えるくらいがちょうどいい。

- 強えヤツってのはな、弱えヤツを笑わねェんだよ。
- 拳を握る前に、差し伸べる手があるだろ。
- 泣き虫上等。泣いたあとに一歩出りゃ、それで十分だ。
- 勝つためだけに強くなるんじゃねェ。守りたいもんがあるんだろ。
- 優しさを持てねェ強さなんざ、ただの力自慢だ。

※ここにある名言はすべて制作用のオリジナル案で、原作から引用したものではない。新しく作ったら、公開前に「原作のセリフと似すぎていないか」をWeb検索で確かめる。

## 4. 香ばしさのさじ加減

- 1本の動画で、劇画モードは**全体の3分の1まで**。残りは温かい3D（FLATUPの本来の絵）で見せる。
- 劇画は「親の不安」「子どもの妄想」「勘違い」の中だけで使う。現実のFLATUPは、いつも明るく優しく描く。
- 大げさな独白のあとには、必ず**素に戻る一言**を入れる（例：「……でも、チャイルドシートちゃんと付けてる。」）。笑いと安心が同時に来るのが、FLATUPらしさ。

## 5. ジョジョ風の名言の使い方（レベル分け）

原作の名言を**そのまま**使うのは避ける。短い言葉は著作物と認められにくいが、作品を強く連想させる名言をジムの宣伝に使うと、公認と誤解されたり、権利者から指摘を受けたりするおそれがある。そのため、次の3段階で使い分ける。

| レベル | 中身 | 使ってよい場所 |
|---|---|---|
| **A：リズムだけ借りる** | 言葉はオリジナル。テンポや言い切り方だけ借りる | どこでも |
| **B：匂わせが強い** | 原作の名言の「形」をはっきり借りた替え歌（パロディ） | 社内で使うのはOK。公開する前にJINが確認する |
| **C：原作の名言そのまま** | 一字一句、原作どおり | 使わない |

**レベルA（そのまま使える）**
- この一歩は、昨日のオレを越えていく一歩だッ！
- 怖いと思った。だから、ここに来たんだ。
- 強さってのはなァ……弱さを知ってるヤツにしか、育たねェんだッ！
- ミットが鳴った。その音が、オレの答えだ。
- やさしさは、受け継がれる。拳じゃなく、手のひらで。

**レベルB（公開する前に確認）**
- 震えるぜミット！ 鳴り響くほどビート!!
- この半歩が、ケガ人ゼロの証明だッ！

**ジョジョ風の演出キット**
- **擬音の文字**：「ゴゴゴ」「ドドド」を、背景いっぱいに大きく斜めに置く（一般的な擬音なのでOK。ただし原作と同じ書体にはしない）
- **キメポーズ**：体を大きくひねった、FLATUPオリジナルのポーズを作る。原作キャラの特定のポーズは再現しない
- **解説役**：周りの人物が「な……何ィ!? 今のは……！」と、技の意味を大げさに説明する。FLATUPでは、**ケガをさせない技術の凄さ**を解説させる
- **部の構成**：シリーズを「第1部・第2部」と分け、主人公が替わっても「やさしい強さ」が受け継がれる
- **使わない**：「スタンド」などの固有の用語、キャラの外見、作品名、ロゴ、書体

## 6. 研究データベースの使い方

1. `works_database.csv` の「演出の特徴」「ギャグの特徴」「FLATUP活用案」の列から、使いたい技法を探す。
2. 「著作権上の注意」の列で、避けるべき要素を確かめる。
3. 「確認状態」が「未確認」の行は、事実（作者・巻数など）を外に出す前に確かめ直す。
4. 「ネットの評判」は [事実] [感想] [推測] に分けてある。宣伝文に使うのは [事実] だけにする。

## 7. 絵柄の参考：不良漫画のリアル劇画（2026-10-30 JINが参考画像を提示）

JINが「絵のイメージ」として見せた参考は、高橋ヒロシ作品（『クローズ』『WORST』）の公式イラスト。**画像そのものは、生成の参照に使わない・リポジトリに保存しない**（作品の絵をそのまま写してしまうため）。かわりに、絵柄の特徴を言葉にして、オリジナルのキャラで使う。

**使う場面**：ヒャッハー三人衆、劇画の妄想、不良漫画のパロディの場面。FLATUPのジムの場面と、子どもが主役の場面は、今までどおり温かい絵柄にする。

| 特徴 | 中身 |
|---|---|
| 頭身 | 大人は7〜8頭身のリアルな体つき。肩幅が広く、首が太い |
| 線 | 筆で描いたような太くて強い輪郭線。顔のしわ、筋肉、服のしわまで線で描く |
| 影 | 黒ベタを大きく置く。細かいハッチング（平行線の影）を重ねる |
| 顔 | 彫りの深い顔、太い眉、細く鋭い目。叫ぶときは口を大きく開け、目を見開く誇張 |
| 服 | 黒い革ジャン、ワークジャケット、ヘンリーネックのシャツ、チノパン、太いベルト、ウォレットチェーン |
| 髪 | 坊主、角刈り、短いオールバック |
| 立ち方 | 片手をポケットに入れて、少し斜めに立つ。力を抜いた、かっこいい立ち方 |
| 色 | 白黒、または彩度を落とした色に、黒い服がしまる配色 |

**オリジナルにするための決まり**
- 参考にしたキャラの顔・髪型・傷・服の組み合わせを、そのまま写さない。三人衆は、黒田＝角刈りに丸いサングラス、黒川＝細いサングラスにパーカー、黒木＝大きすぎるサングラスにぶかぶかの革ジャン、のFLATUPオリジナルの姿に固定する。
- チーム名、刺しゅうの文字、ブランドのロゴ、作品のロゴ、校章は描かない。背中や胸の文字は空けるか、意味の読めない崩しにする。
- **怖さより、かっこよさと間抜けさ**。バイブルは「怖い顔」を禁じているので、叫ぶ顔は、汗のしずく、ずれたサングラス、つぶらな目など、笑える要素を1つ必ず足す。子どもが出る話では、劇画の顔のアップを使わない。
- 「強さとは、かっこよさ」の場面（黒田が人を守る、礼をする）は、2枚目のような力の抜けた立ち方で、静かにかっこよく描く。

**画像プロンプトのブロック（英語）**
```
gritty Japanese delinquent manga style, realistic adult proportions with broad shoulders and thick neck,
bold brush-ink outlines, heavy black shadows, dense crosshatching, deeply carved facial features,
thick eyebrows, sharp narrow eyes, black leather jacket, work jacket, henley shirt, chino pants, wallet chain,
relaxed cool stance with one hand in a pocket, desaturated colors or black and white,
original character design, no team names, no embroidered text, no logos, no brand marks, no tattoos, no blood
```
- 叫ぶ場面では、最後に `comedic exaggerated shouting face, sweat drops, sunglasses slipping, silly rather than scary` を足す。
- 守る・礼をする場面では、最後に `calm dignified expression, quiet cool atmosphere` を足す。
