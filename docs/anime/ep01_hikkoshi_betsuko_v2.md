## 3. 文字の決まり（無音でも、スマホの実寸でも分かるように）

数は `../emotional_movie_ep0_edit.md` の「編集ルール」「字幕の置き場所」に合わせた（Instagram のリールの実機で測った数）。

| 項目 | 決まり |
|---|---|
| 作り方 | 日本語の文字は**すべて編集で重ねる**（検索の語、伝票、付箋、描き文字、字幕、タイトル）。画像の生成には `no text` を入れる |

| 大きさ | 幅1080pxで1文字50px以上。1行18字まで。2行まで |
| 速さ | セリフ・ナレーションの字幕は1秒7字まで（最短1.2秒、字幕どうしの間は0.2秒以上）。検索の語・伝票・付箋など「置く文字」は1秒12字まで |
