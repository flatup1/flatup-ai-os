**台本の点検メモ**

- 合計45.0秒（★のすきまなし）。字幕は4本＋置く文字2本。いちばん速いのは★1の1秒5.4字（7字の上限の中）
- **無音でも分かるか**：字幕を消しても、リュックが大きい → 劇画の大げさ → パパがあきれる → 眠れないママ → 手をはなす → 宙の手 → 重いリュック → 1枚だけのティッシュ → 手を取る、で筋が通る。読まないと困る文字は「ママ用」（3字）だけ
- **最後に教訓を読み上げない**：ナレーションなし。最後のセリフは★12の「……おもっ。」
- **先生の説教で解決しない**：マサキは「こんばんは！」だけ。話を動かすのは、栄光くんが手をはなす選択（★8）、ママが追いかけない選択（★10）、パパが言わない選択（★14）
- **予約を迫らない**：料金・時間・年齢・「体験」「入会」の言葉なし。ジム名は最後のカードだけ。次の話への期待は、投稿文に次の題名を書く（設計書 §4）
