# 誰でも使えるための決まり（このアプリのUX正本）

対象は「老若男女」。いちばん厳しい条件＝**70代・スマホに不慣れ・老眼**に合わせる。
そこに合えば、ほかの人には自動的に使える。

---

## 1. 破ってはいけない8つ

| # | 決まり | どこで守っているか |
|---|---|---|
| 1 | 主要な操作はホームから**3タップ以内** | `smartglass.test.ts`「3タップ以内で写真を見る」 |
| 2 | 押せるものは**48dp以上** | `ui/tokens.ts` `MIN_TAP_TARGET_DP` ＋ テスト |
| 3 | 文字は**4段階**で変えられる。既定は「大」 | `settings.setFontScale()` ＋ テスト |
| 4 | 音声と画面の**両方**で伝える | `app.speak()`（音声ガイドが入のときだけ） |
| 5 | エラーは「**何が起きたか**」＋「**次にどうするか**」 | `errors.ts` ＋ 全コードのテスト |
| 6 | 接続状態と電池は**ホームに常時・大きく** | `HomeView.statusText` / `batteryText` |
| 7 | 専門用語を画面に出さない | テスト「専門用語をそのまま画面に出していない」 |
| 8 | コントラストは **WCAG AA（4.5:1）以上** | `contrastRatio()` ＋ テスト |

これらは全部**テストで機械的に見張っている**。
あとから画面を足しても、決まりが崩れたらテストが落ちる。

## 2. 「迷いどころ」を作らない設計

いちばん効いているのはここ。

**ホームの押しどころは、いつも1つだけ。**

| いまの状態 | 主役ボタン |
|---|---|
| つながっていない | 「メガネにつなぐ」 |
| 一度失敗した | 「もう一度つなぐ」 |
| さがしている・つないでいる | （押せない） |
| つながっている | 「写真を取り込む」 |
| 取り込めなかったぶんがある | 「取り込めなかったぶんを、もう一度取り込む」 |
| 取り込み中 | （押せない） |

「どのボタンを押せばいいのか」という問いが、そもそも生まれない。
実装は `app.ts` の `primaryAction()` 一箇所。

## 3. 文字とボタンの大きさ

| 段階 | 本文 | ボタンの文字 | 主役ボタンの高さ |
|---|---|---|---|
| 小 | 16pt | 18pt | 72dp |
| 中 | 18pt | 21pt | 83dp |
| **大（既定）** | **22pt** | **24pt** | **97dp** |
| 特大 | 26pt | 29pt | 115dp |

**文字を大きくすると、ボタンも一緒に大きくなる。**
文字だけ大きくして枠がそのままだと、字が切れて逆に読めなくなるため
（`tapTargetHeight()` が倍率を掛ける）。

## 4. 色

色だけで意味を伝えない。**かならず文字も添える**（色覚多様性・白内障への配慮）。

| 役割 | 色 | 背景とのコントラスト |
|---|---|---|
| 本文 | `#1A1A1A` | 18.9:1 |
| 補足 | `#4A4A4A` | 9.1:1 |
| つながっている | `#0B6B3A` | 6.6:1 |
| 注意 | `#8A4B00` | 6.6:1 |
| うまくいかなかった | `#A4123F` | 7.3:1 |
| 主役ボタン | `#0B4F9E`（文字は白） | 8.1:1 |

## 5. 目標

| 指標 | 目標 | どう測るか |
|---|---|---|
| 初回ペアリング完了率 | 90%以上 | 「はじめての方へ」の到達段階を記録 |
| 「写真を取り込んで見る」までの時間 | 平均3分以内 | 初回起動〜ギャラリー初表示 |
| 60歳以上の「使いやすい」評価 | 4.0 / 5.0 以上 | 設定の「ご意見・不具合を送る」 |

計測は端末の中だけで数え、送るのは利用者が自分で押したときだけ。

---

## 6. アクセシビリティ

- 押せるものすべてに `accessibilityRole` と `accessibilityLabel`（VoiceOver / TalkBack）。
- 進み具合は `accessibilityRole="progressbar"` ＋ 件数の読み上げ。
- エラーは `accessibilityRole="alert"`。
- 翻訳の言語は**国旗だけにしない**。かならず日本語名を添える。
