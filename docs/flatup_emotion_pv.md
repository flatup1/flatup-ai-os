# FLATUP GYM 感情設計PV（不安 → 希望 → 自信）

**目的**: 機能（料金・設備・カリキュラム）ではなく**感情**で動いてもらい、
**LINE友だち追加**という一番小さな一歩へ誘導する。

> 📖 キャラ・世界観の正本 → [flatup_animation_bible.md](flatup_animation_bible.md)

---

## なぜ感情設計なのか

見込み客（多くは**保護者**、または運動から離れた大人）が本当に抱えているのは
「料金がわからない」ではなく、**こわい・場違いかも・続かないかも**という不安。

だから訴求の順番は次になる。

```
①不安に共感する  →  ②希望を見せる  →  ③自信の姿を見せる  →  ④一番小さな一歩を出す
「わかるよ」        「大丈夫だよ」      「こうなれるよ」      「まずLINEだけ」
```

**機能訴求は最後まで出さない**。料金や設備を先に出すと「比較検討」の頭に切り替わり、
感情が動かなくなる。

## 感情カーブ（5幕＋CTA）

| 幕 | 感情 | 見せる画 | 字幕 | 秒 |
|---|---|---|---|---|
| ① | **不安** | 窓の外から中をのぞく子 | 「入るのが、こわかった。」 | 6 |
| ② | **希望** | メルティが目線を合わせる | 「大丈夫。ゆっくりでいいよ。」 | 7 |
| ③ | **挑戦** | マサキと並んでパンチ | 「一歩ずつ、一緒に。」 | 7 |
| ④ | **自信・喜び** | グローブをつけて笑う子 | 「できた！」 | 7 |
| ⑤ | **余韻** | 夜のジム・サンドバッグ | 「また明日ね。」 | 5 |
| CTA | **行動** | エンドカード | 「まずはLINEで話してみる」 | 4 |

**合計 約36秒**（ショート動画の完視聴率が落ちにくい尺）

### 各幕の狙い

- **①不安**: 主人公を「まだ入っていない子」にする。**視聴者＝まだ来ていない人**と重ねる。
  ここで笑顔を出さない。出すと共感が飛ぶ
- **②希望**: 解決策を「設備」ではなく**人（先生の一言）**で見せる。安心は人から来る
- **③挑戦**: できるようになる過程。**上手である必要はない**。並んでいることが大事
- **④自信**: 変化後の喜び。ここが最大の山。**笑顔を一番大きく使う**
- **⑤余韻**: 「明日も来たい」を示し、継続のイメージを残す
- **CTA**: 迷いが冷めないうちに、**一番小さな行動**を1つだけ提示する

## CTAの原則

**やること**
- 出す行動は**1つだけ**（LINE友だち追加）
- ハードルを言葉で下げる: 「予約じゃなくて大丈夫」「質問だけでもOK」
- 料金はここで**はじめて**、しかも小さく出す（初回体験 30分・500円）

**やらないこと**
- 「今すぐ予約！」の圧
- 電話・メール・フォームなど**複数の導線を並べる**（迷って離脱する）
- 期間限定・残りわずかの煽り（バイブルの「押し売りしない」に反する）

## 制作方法

素材は既存クリップの並べ替えで作れる。動きを足すため、各カットに
**ゆっくりした寄り（1.0→1.08倍）**を掛けて、静止感を消している。

```bash
# 既存クリップから感情設計PVを組む
bash scripts/flatup_emotion_pv.sh
```

- 出力: `output/pv/flatup_emotion_pv_YYYYMMDD.mp4`（1080×1920 / 30fps / 無音）
- BGMはCapCutで足す。**①で静か → ④で開く → ⑤で余韻**の曲を選ぶ

## 効果測定（次に回すため）

投稿ごとに次を記録すると、感情設計の当たり外れが分かる。

| 指標 | 見るポイント |
|---|---|
| 3秒視聴率 | ①の不安の画が刺さっているか |
| 完視聴率 | ④の山まで持つか。落ちるなら尺が長い |
| **LINE友だち追加数** | 本命指標。CTAの文面を変えて比較する |
| 体験申込数 | 追加後の会話設計（AIKAの返信）側の課題 |

数字が動かないときは、**①の不安の言い方**から直す。ここが刺さらないと以降は見られない。
