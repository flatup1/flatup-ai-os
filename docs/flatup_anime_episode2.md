## 基本仕様

| 項目 | 値 |
|---|---|
| 尺 | 約45秒（6秒×8カット） |
| 画面 | 縦 9:16 |
| 画風 | EP1と同じ（温かい3D映画風・怖くしない） |
| 登場 | ツム(5・主人公) / リク(7) / メルティ(28・女性インストラクター) |
| 費用 | cheap 約$0.3 / full 約$13 |

## お話

ツムはまだ「ありがとう」が言えない。
グローブを落として困っているところを、リクが拾ってくれる。
言葉が出ずうつむくツムに、メルティが目線を合わせて寄り添う。
小さく息を吸って、ツムは自分の言葉で伝える。

## 絵コンテ（8カット）

| # | 画（何が見えるか） | 動き | 字幕 |
|---|---|---|---|
| 1 | 朝のジム入口。ツムがグローブを抱えて一人で立っている | グローブを抱え直し、おずおずと顔を上げる | ツム、5さい。 |
| 2 | ツムがグローブを片方落とす | グローブが床に落ち、ツムが固まる | あっ… |
| 3 | リクがしゃがんで拾い、笑顔で差し出す | 拾って差し出す | はい、どうぞ！ |
| 4 | 両手で受け取るツム。言葉が出ない | 口を開きかけて、うつむく | …（言えない） |
| 5 | メルティが目線を合わせて話しかける | 膝をついて優しく語りかける | ゆっくりでいいよ |
| 6 | ツムが小さく息を吸って顔を上げる | 一呼吸して、静かな決意の表情 | すぅ… |
| 7 | ツムが笑顔で軽く礼をする。リクも笑顔 | お辞儀 → 二人が笑い合う | ありがとう！ |
| 8 | みんなで並ぶ。ツムもその中にいる | ゆっくり引いて締める | 世界一やさしい格闘技ジム |

> **共通ルールの充足**: あいさつ(1) / 礼(7) / 笑顔(7,8) / 仲間を応援(3,5) / ありがとう(7) / 自分で考える(6)
> **安全**: 誰も傷つかない。怖い顔・叱責は描かない（`no scary faces` を全カットに付与済み）

## プロンプト

カット別のFLUX画像プロンプトとHailuo動画プロンプトは **`src/reel/animeEpisodes.ts` の `EP2_CUTS` が正本**。
生成コマンドはそこを参照するので、直すときはコード側を直す（ドキュメントとコードの二重管理を避けるため）。

字幕表はいつでも次のコマンドで出せる:
```bash
npm run anime:subtitles -- --episode 2
```

## 編集メモ（CapCut）

- **BGM**: EP1より少し静かに始め、カット6〜7で温かく開く
- **効果音**: グローブが落ちる音（カット2）、子どもたちの笑い声（カット7〜8）
- **間**: カット4は**あえて少し長めの沈黙**を作ると「言えなさ」が伝わる
- **ロゴ**: 最後の1秒のみ
