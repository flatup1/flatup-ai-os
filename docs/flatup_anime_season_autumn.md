# FLATUP アニメ EP5「秋、心を整える」（秋・新学期）

**テーマ**: 落ち着きと集中力の大切さ  
**対象**: 子ども・親世代（集中力・学習習慣を身につけたい全員）  
**時間**: 36 秒  
**CTA**: 「秋の入会キャンペーン」

---

## ストーリー概要

秋の静かな時間。ツムが瞑想的な深呼吸で心を落ち着ける。  
リク先輩が集中力を教え、メルティが心を読む優しさ。  
マサキが承認する。秋の深い色合いと、みんなで調和する映像。

---

## 感情曲線

```
① 静けさ（落ち着き）→ ② 深呼吸（内観）→ ③ 教え（学び）
→ ④ 理解（共感）→ ⑤ 向き合う（挑戦）→ ⑥ 承認（喜び）
→ ⑦ 調和（一体感）→ ⑧ 秋、心を整えた（達成）
```
