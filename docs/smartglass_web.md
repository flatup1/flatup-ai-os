# スマートグラス Webアプリ（ブラウザで見る）— 正本

**やること**: メガネで撮った写真を、**Mac と iPhone のブラウザ**で見る。
アプリのインストール不要、Apple登録不要、費用0円、写真は家の外に出ない。

---

## なぜ「橋渡し役」が要るのか

ブラウザだけでは、メガネから写真を取れません。壁が2つあります。

1. **iPhone の Safari は Web Bluetooth に対応していない**（Chrome でも不可）
2. **ブラウザは Wi-Fi を切り替えられない** —
   メガネは自分の Wi-Fi を出して、そこに HTTP で写真を置く仕組みなので、
   そのWi-Fiに入れないと1枚も取れない

そこで **Mac が橋渡しをします**。

```
  メガネ ──(メガネのWi-Fi)──▶ Mac ──(家のWi-Fi)──▶ ブラウザ
                               ↑                    ├─ Mac    : http://localhost:8787
                        小さなサーバが常駐            └─ iPhone : http://192.168.x.x:8787
```

---

## 使い方

```bash
# 1回目だけ: メガネの電源を入れ、Mac の Wi-Fi 一覧に出る名前を確かめる
npm run glasses:web -- --ssid "HeyCyan-XXXXXXXX"
```

起動すると、開くURLが2つ表示されます。**iPhone は Mac と同じWi-Fi**で開いてください。

画面の大きなボタン「**写真を取り込む**」を押すと:

```
Wi-Fiをメガネ側へ切替 → 一覧を読む → 1枚ずつ落とす → 家のWi-Fiへ戻す → 画面が自動で更新
```

取り込み中の十数秒だけ、Mac が家のネットワークから外れます（iPhone から一時的に見えません）。
終われば自動で戻り、開いている全部のブラウザに**押し届け**されます（リロード不要）。

| 指定 | 意味 | 既定 |
|---|---|---|
| `--ssid` | メガネのWi-Fiの名前（**必須**） | — |
| `--password` | メガネのWi-Fiのパスワード | `123456789` |
| `--port` | 開く番号 | `8787` |
| `--dir` | 写真の置き場 | `~/FLATUPスマートグラス` |
| `--home-ssid` | 戻り先の家のWi-Fi | 切替前の接続先を自動で覚える |

環境変数 `GLASSES_SSID` / `GLASSES_PASSWORD` / `GLASSES_PORT` / `GLASSES_DIR` でも指定できます。

## できること

| 画面 | できること |
|---|---|
| 上の帯 | いまの状態と、取り込みの進み具合（棒＋「3枚中1枚」） |
| 大きなボタン | 写真を取り込む／取り込めなかったぶんをもう一度 |
| 一覧 | 日付ごと（きょう・きのう・8月25日）に大きなサムネイル |
| 押すと | 全画面。動画は再生、音声は再生 |
| 保存 | ブラウザに保存（iPhone は長押しで写真アプリへ） |
| 共有 | iPhone は共有シート（LINE・メール）、Mac はURLをコピー |
| 設定 | 文字の大きさ 小・中・大・特大（既定は「大」） |

## 作り

```
src/smartglass/
├── （共通の中身。スマホ版とまったく同じものを使う）
│   protocol/ device/ transfer/ gallery/ ui/ i18n.ts errors.ts help/
└── web/
    ├── nodePlatform.ts  Mac用の差し込み口（HTTP・保存・Wi-Fi切替）
    ├── server.ts        node:http だけのサーバ。SSEで押し届け
    ├── page.ts          ブラウザに出す1枚のHTML（ビルド不要）
    ├── serve.ts         起動するだけの入口
    └── web.test.ts      偽のメガネを立てて、本物のHTTPで通しテスト（10件）
```

判断（つなぐ・取り込む・並べる）は core にあり、**Web版はそれを別の入れ物に載せ替えただけ**です。
だから文言・色・文字の大きさ・エラーの書き方は、スマホ版と1つに保たれます（テストが見張っています）。

```bash
npm run test:glasses       # 中身の回帰（54件）
npm run test:glasses:web   # Web版の通し（10件・本物のHTTP）
```

Web版のテストは**偽のメガネ（HTTPサーバ）を実際に立てて**、
一覧の取得 → ダウンロード → 途中で切る → `Range` で続きから → ブラウザに配信、
までを本物のネットワークとファイルで確かめています。

## 気をつけていること

- **目録にあるものしか返さない** — URLでパスを直接受け取らないので、外のファイルは読めません。
- **取り込み中に切れても壊れない** — 途中まで受け取ったバイト数を覚え、`Range` で続きから。
  半分で切られたファイルが「壊れたまま残らない」ことをテストで確認しています。
- **家の中だけ** — 写真はクラウドに送りません。Mac の中に置き、家のWi-Fiの中だけで配ります。

## まだ無いもの（正直に）

| 無いもの | 影響 | 代わり |
|---|---|---|
| BLEでの自動接続 | メガネのWi-Fi名を最初に1回教える必要がある | `--ssid` で指定（1回だけ） |
| 動画のサムネイル | 動画は種類の札だけで並ぶ | 押せば再生できる |
| AI・翻訳 | Web版にはまだ無い | スマホ版（`smartglass-app/`）に実装済み |
| Windows / Linux の Wi-Fi 自動切替 | 自動で切り替わらない | 手で Wi-Fi を選べば同じように動く |
