## 第0話の方針
- BGM: 夜の会議は木琴・ピアノ・柔らかい弦。回想はピアノ中心。最後は静かな希望
- 「ううん。」の直後に**1拍だけ無音に近づける**（物語の転回点）
- 手が離れるカットは BGM を薄く、SE も入れず**間で見せる**
- ミットを打つ音は軽く。絶対に強くしない
- v1 は音声セリフなし。SE と間で感情を運ぶ

秒単位のキューは `npm run movie -- edl` の出力に含まれる。
