# 12 Webシステム

## 状態: ❌ 存在しない

外部提案に「React / Next.js / TypeScript / Node / Docker のAIアニメ生成ツール」
とあったが、**このリポジトリにそのようなWebシステムは無い**。

現在の制作基盤は次のとおりで、Webサーバもフロントエンドも使っていない。

- Node.js + TypeScript（tsx で直接実行）
- **依存パッケージ ゼロ**（Node 18+ の標準 fetch のみ）
- CLI（`npm run movie -- ...`）と Mac のシェルスクリプト
- fal.ai の HTTP API を叩くだけ
