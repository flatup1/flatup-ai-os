## 絶対に破らない
1. **送信・投稿・請求・契約変更・規約判断は人間（JIN）が行う。** AIは下書きまで
2. ファイル削除・大規模移動・commit・push は JIN 承認後
3. 整理は「提案 → 承認 → 実行」の順
4. 生データ（PDF・画像・動画）は GitHub 管理しない
5. **テストを消して回避しない。** テストは過去に実際に起きた事故の記録

片方だけ直すと、正本が二重になって崩れる。
