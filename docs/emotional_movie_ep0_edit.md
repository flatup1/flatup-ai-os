# 第0話 編集設計（35秒版／15秒版）

**正本**: [emotional_movie_ep0.md](emotional_movie_ep0.md) の「完成台本（改訂版・35秒）」
**実体**: `src/movie/editPlan.ts`（数値の正本。ここの文章はその読み物）
**検査**: `npm run test:movie`（17ケース。尺の穴・字幕の読み速度・素材IDを機械的に確認）

## これは何か

台本と素材リストはあったが、「**どの素材を・何秒目に・どう動かして・どの字幕と一緒に置くか**」が決まっていなかった。
Day 3 の仮編集はこれが無いと勘で並べることになるので、先に数字で決めた。

書き出しはいつでもできる（**API もネットワークも要らない**）:

```bash
npm run movie -- edl                    # 35秒版と15秒版の両方
npm run movie -- edl --plan ep0-15s     # 片方だけ
```

出力:
- `output/movie/ep0/edit/ep0-35s.md` … 編集台本（CapCutを触りながら読む）
- `output/movie/ep0/edit/ep0-35s.srt` … 字幕。CapCutにそのまま読み込める

## 設計中に見つかった問題と、その処理

### ① Scene 1 に字幕が物理的に入らなかった

台本の Scene 1 は **0〜3秒**。そこに置く字幕は

- 「閉館後のジムで、毎晩ひらかれる——」（17字）
- 「秘密の会議。」（6字）

合計23字。日本語字幕が読める速度は**毎秒6〜7字**が上限なので、**3.4秒以上必要**。3秒には入らない。

**処理**: 字幕トラックをカット割りから独立させた。字幕はカットをまたいで良い。
1本目を 0.4〜3.2秒（カットをまたぐ）、2本目を 3.4〜5.2秒に置いた。
**台本は変えていない**。シーンの区切り秒（3/7/13/17/26/31）は正本どおりで、テストが固定している。

### ② Scene 6 の「ほんの少し。でも、ちゃんと、強くなった。」が読めなかった

最初 2.4秒で置いたら **8.3字/秒**。テストが落ちて気づいた。20字なら 2.9秒以上要る。

**処理**: 前の「本日のチャンピオン、決定。」をカット頭の 26.0秒ちょうどから始めて詰め、
後ろへ尺を寄せた。結果 28.3〜31.3秒（3.0秒 / 6.7字/秒）。
これも台本の文言は変えていない。

### ③ CTA カードを字幕と同じ規則で測るのは間違いだった

15秒版の CTA「キッズ体験 500円／火・木 18:00〜」は 29字。字幕の規則だと 10.4字/秒で不合格になる。
だが CTA は**流れる字幕ではなく、置いてある情報**で、視線で拾うものなので速度の意味が違う。

**処理**: `kind: "card"` を分けた。カードは読み速度の上限を 12字/秒に緩め、
代わりに**最低2.5秒は画面に置く**ことを要求する（目に入る時間の確保）。
35秒版の末尾ロゴは、そもそも文字ではなく画面デザインなので字幕トラックに入れていない。

## 35秒版の骨子

| 秒 | シーン | 素材 | ねらい |
|---|---|---|---|
| 0–3 | 1 目覚め | **V1**（動画） | 3秒で掴む。黒画面で始めない |
| 3–7 | 2 夜のジム | C2 | 引き→寄りで世界を見せる |
| 7–13 | 3 秘密の会議 | C3 | 唯一の軽い場面。**尺に余裕がある＝困ったらここから借りる** |
| 13–17 | 4 ミスリード | C4 | 意図的に「強い子が正解」に見せる |
| 17–26 | 5 小さな勇気 | C5a→C5b→**V2**→**V3**→C5e→C5f | 感情の核。6カット |
| 26–31 | 6 決定 | C6 | 夜へ戻る。タイマーに光が1つ灯る |
| 31–35 | 7 朝 | **V4**（動画） | 朝日＋ロゴ |

太字が image-to-video で作る4カット。それ以外は静止画＋ゆっくりした寄り／引き。

### Scene 5（感情の核）の中の配分

| 秒 | 素材 | 長さ | 意図 |
|---|---|---|---|
| 17.0 | C5a | 1.2s | 隠れている。短く置くだけ |
| 18.2 | C5b | 1.4s | 先生がしゃがむ。空気がやわらぐ |
| 19.6 | **V2** | **2.6s** | ★手が離れる。**このシーンで一番長い**。BGMを薄く、SEも消す |
| 22.2 | **V3** | 1.6s | 一歩前へ |
| 23.8 | C5e | 1.2s | はじめてのミット。音は軽く |
| 25.0 | C5f | 1.0s | 母の表情。長く見せると狙いが透ける |

**V2 に重ねる字幕は「今日、はじめて『ひとりで前に出た』子。」の1本だけ**。
ここに説明を足すと台無しになるので、テストで本数を固定してある。

> **仮編集で Scene 5 が忙しく感じたら**: 母の表情（C5f・1.0秒）が短い。
> Scene 3 が6秒あって一番余裕があるので、**そこから1秒借りて C5f を2.0秒にする**のが第一手。
> その場合、後ろのシーン境界が1秒ずつズレるので `editPlan.ts` を直してテストを通し直すこと。

## 15秒版（広告用）

正本の指示どおり、**35秒版の切り出しではなく再設計**。使うのは**動画4カットだけ**（V1/V2/V3/V4）。
無音で見ても物語が成立する最小構成にしてある。テストが「素材が V1〜V4 の4本だけであること」を固定している。

| 秒 | 素材 | |
|---|---|---|
| 0–3 | V1 | 掴みは35秒版と同じ（3秒視聴維持率を落とさないため変えない） |
| 3–6.5 | V2 | ★手が離れる。**35秒版より0.9秒長い**。15秒版はここが主役 |
| 6.5–9 | V3 | 一歩前へ。ここまでで物語が成立する |
| 9–12 | V4 | 朝＋ロゴ |
| 12–15 | CTAカード | 生成せず CapCut の図形＋文字で作る |

## 編集ルール（テストが検査する数値）

| 項目 | 値 | 理由 |
|---|---|---|
| 字幕の読み速度 | 7字/秒 以下 | 超えると読み切れない |
| カードの読み速度 | 12字/秒 以下 | 組まれた情報は視線で拾えるので速い |
| 字幕の最短表示 | 1.2秒 | 短いと読む前に消える |
| カードの最短表示 | 2.5秒 | 情報量が多い |
| 字幕どうしの間隔 | 0.2秒 以上 | 入れ替わりが認識できない |
| 1カットの最短 | 1.0秒 | チラつく |
| 字幕の行数 | 2行 以下 | 縦型で3行は読まれない |
| 1行の文字数 | 20字 以下 | 縦型9:16で折り返さない上限 |

### セーフゾーン（1080×1920）

| | 余白 |
|---|---|
| 上 | 120px |
| **下** | **420px** |
| 左右 | 60px |

下を大きく取るのは、**Reels / Shorts は下部にUI（キャプション・いいね・シェア）が重なる**ため。
字幕をここより下に置くと隠れる。CapCut のセーフゾーン表示だけを信じないこと。

## テストが守っていること

`npm run test:movie` で17ケース。特に効くのは:

- **カットが隙間なく・重ならず・宣言した尺ぴったりに並ぶ** … 合計が35.0秒でないと落ちる
- **素材IDが promptBank に実在する** … `C5g` のような打ち間違いを弾く
- **動画カットが生成尺に収まる** … 4秒しか生成しないのに5秒使う設計を弾く
- **字幕が読める速度に収まる** … 上の②を見つけたのはこれ
- **シーンの区切りが台本どおり** … 3/7/13/17/26/31 が崩れたら落ちる
- **V2 に重なる字幕が1本だけ** … 最重要カットに説明を被せない
- **15秒版が切り出しになっていない** … 素材が V1〜V4 の4本であること
