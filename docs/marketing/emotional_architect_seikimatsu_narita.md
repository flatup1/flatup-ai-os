# エモーショナル・アーキテクト設計書：「世紀末ナリタ × FLATUP GYM」

**テーマ（仮）**：AI時代に、体と技と優しさを鍛える場所 ―― 世紀末ナリタとFLATUP GYM
（依頼のテンプレートはテーマ欄が空だったため、進めている漫画・アニメ企画をテーマとして設計した。別のテーマにするときは §4 のプロンプトの【テーマ】だけ差し替える）

**結論**：主人公は顧客、FLATUPは**師匠と道場**。感情のトリガーは「不安を笑ってもらえる安心」と「小さな成功」。旗印は「強さとは、優しさだ」。宣伝より先に、物語を好きになってもらう。

---

## 1. 物語のレンズ：顧客の人生で、FLATUPは何の役か

| 物語の要素 | 世紀末ナリタでの姿 | 現実の顧客 |
|---|---|---|
| 主人公 | ヒャッハー三人衆、引っ越してくる親子 | 運動が苦手な大人、子どもを心配する親、仕事に不安がある人 |
| 日常の崩壊 | AIに仕事を奪われた世紀末 | 「このままでいいのか」という漠然とした不安 |
| 冒険への誘い | 「初心者歓迎」の看板 | SNSで漫画を見て、少し気になる |
| ためらい | 「なめやがって」→「ほんとに初心者でもいいの？」 | 怖そう、きつそう、笑われそう |
| 師匠との出会い | マサキが半歩よけて、守ってくれる | 体験レッスンで、怒鳴られずに教わる |
| 最初の試練と小さな勝利 | 太ももが伸びた、ミットがいい音で鳴った | 初めてのミット打ちができた |
| 帰還と変化 | 「来週も、来ていいスか」 | 入会し、仲間ができる |

**FLATUPは主人公ではない。** 主役はいつも顧客。FLATUPは、主人公が自分の強さを見つける道場と師匠の役。

## 2. 心理のレンズ：どんな気持ちが人を動かすか

| トリガー | 仕組み | 世紀末ナリタでの使い方 | やってはいけないこと |
|---|---|---|---|
| 不安を言い当てられる安心 | 自分の不安を先に言葉にしてもらうと、人は「わかってもらえた」と感じて心を開く | 三人衆に「腕立て0回なんスけど」と言わせる | 不安をあおって焦らせる |
| 笑いで怖さを下げる | 笑うと、怖い対象との心の距離が縮まる | 劇画の大げさな妄想 → すぐに素に戻る一言 | 誰かを笑いものにする |
| 小さな成功体験 | 「できた」がひとつあると、次もやれる気がしてくる（自己効力感） | 「パスンッ！」の一音、伸びた太もも | 「1か月で別人に」のような誇大な約束 |
| 落差による好感 | 怖そうな人が優しいと、印象に強く残る | 黒田が実は二児のパパ、マサキが半歩でよけて守る | 本物の暴力で落差を作る |
| 仲間になりたい気持ち | 価値観を共有する集団に、人は入りたくなる | 「ヒャッハー三人衆、入会」という連続もの | 入らない人を否定する |
| 続きが気になる | 物語が途中だと、続きを見届けたくなる | 次回予告「ヒャッハー、敬語を覚える」 | 毎回「今すぐ入会」と迫る |

## 3. 世界観のレンズ：どんな旗を掲げるか

**宣言（マニフェスト）**

> AIが仕事を覚えても、あなたの体は、あなたにしか鍛えられない。
> 強さとは、相手を倒す力じゃない。弱い人を笑わず、守れる力だ。
> だからFLATUPは、初心者を笑わない。怒鳴らない。置いていかない。
> 世界一、初心者に優しい格闘技ジム。

**3つの合言葉**

1. 「不良漫画は好き。でも不良は嫌い。」（熱さは好き。乱暴は嫌い）
2. 「強さとは、優しさであり、かっこよさである。」
3. 「はじめの一歩を、笑わない。」

**参加したくなる仕掛け（下書き案）**
- 体験に来た人を「入門」と呼ぶ。ジムのことは、劇中で「荒野の灯り」と呼ぶ
- 漫画の各話の最後に、その回の「やさしい強さ」を1行の格言で残す。ファンが集めたくなる
- 実在の会員を漫画に登場させるのは、本人の同意をJINが確認してから

【テーマ】

【ブランドの芯（変更禁止）】

- 強さとは、優しさであり、かっこよさである
- 不良漫画は好き。でも不良は嫌い
- はじめの一歩を、笑わない（怒鳴らない・比べない・置いていかない）

【ターゲット】
1. 運動が苦手で、格闘技は怖そうだと思っている20〜40代の大人

3. AIや仕事の変化に、漠然とした不安を持つ会社員・エンジニア

黒ずくめのヒャッハー三人衆（黒田・黒川・黒木）がジム破りに来て、なぜか体験レッスンを受けて変わっていく。
指導者マサキは、殴らずに半歩でよけ、相手が転ばないように守る。

【3つのレンズで考えること】
1. 物語：顧客を主人公、FLATUPを師匠と道場として描く。主人公の「ためらい → 小さな成功 → 仲間」の流れを作る
