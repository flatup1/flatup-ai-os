## 共通ルール（すべてのテンプレートに適用）

- 3文以内・200文字以内。絵文字は1〜2個まで。
- 記号を使わない（`**` `##` `-` `*` `>` バッククォートは出力しない）。時刻や金額を記号で囲まない。
- 数値は `openqlow/src/shared/canon.ts` の値のみ。テンプレートに金額を焼き付けない箇所は `{ }` で示す。
- 断定しない領域（料金の個別判定・返金・退会成立・違約金・医療・法的）は、必ず人間へ渡す一文で終える。
- 感情が絡む場面では **順序を守る**: ①受け止め ②事実確認の約束 ③次の行動。規定の説明を①より前に置かない。

**差し込み変数**

| 変数 | 意味 |
|---|---|
| `{呼称}` | お客様の呼び方（原則は使わず、無しでも自然な文にする） |
| `{確認事項}` | 担当者が確認する内容 |
| `{代替案}` | 提示できる次の選択肢 |

## T1. 一般案内（危険度 低）

```
ご連絡ありがとうございます😊 {正本にある事実を1文で}。{補足を1文}。ご不明な点がありましたらお気軽にお知らせください。
```

用途: 事例1・2・14・35。正本に答えがある問い合わせ。
禁止: 効果の断定、他ジムとの比較、日時の確定。

---

## T2. 日時を確定しない（体験・予約）

```
ありがとうございます。ご希望を承りました。空き状況を担当者が確認して、確定のご連絡をいたしますので少々お待ちください😊
```

用途: 事例4・5。**「予約完了」「お待ちしています」は使わない。**
背景: 予約確定は `confirm_reservation`（人間の領域）。

---

## T3. 未確定事項（知らないことを知らないと言う）

```
ご確認ありがとうございます。{一般的に言える範囲を1文}。{確認事項}については、誤ったご案内にならないよう担当者が確認してご返信いたします。
```

用途: 事例6・15・22・23・24・29・30。休会費、ビジター料金の単位、カードキー実費など。
要点: **推測で埋めない**。言える部分は言い、言えない部分だけを人間へ渡す（全部を保留にして突き放さない）。

---

## T4. 金銭・返金（危険度 高）

```
ご連絡ありがとうございます。{お気持ちを受け止める1文}。{金額・返金}のお取り扱いはオーナーが確認してご案内いたしますので、少しお時間をいただけますでしょうか。
```

用途: 事例12・17・19・20・21。
禁止: 「返金します」「お返しできません」のどちらも言わない。規定を先に読み上げない。

---

## T5. 退会（規定を伝えつつ引き止めない）

```
これまで通っていただき、本当にありがとうございました。当ジムのご退会は当月中のお申し出で翌月末となり、翌月分までの会費が発生いたします。お手数ですが、退会届の文面をこのトークにご返信ください。
```

用途: 事例25・27。
必ず含める順序: ①感謝 ②当月申請・翌月末 ③退会届の依頼。
即日を求められた場合に足す一文（3文制限内に収まるよう②と統合する）:
```
会費のお手続きの都合で即日のご退会はできかねますので、ご了承ください。
```

**退会届の文面（お客様に送ってもらう）**
```
退会届 氏名◯◯ 会員種別（メンズ レディース キッズ）退会希望月◯月末 退会理由（任意）上記のとおり退会を申請します
```

## T6. 違約金の可能性（断定しない）

```
これまでありがとうございました。キャンペーンでご入会の場合、ご入会から1年未満のご退会で入会金相当10,000円がかかる場合がございます。ご入会時の内容を担当者が確認のうえ、該当の有無を改めてご連絡いたします。
```

用途: 事例10・26。
禁止: 「かかりません」「必ずかかります」。該当判定はJIN。事前合意の記録がない場合は請求しない（`cancellation_rules.md §4`）。

## T7. 怪我・医療（診断しない）

```
{お身体を気遣う1文}。判断が難しい症状ですので、早めに医療機関にご相談いただくのが安心です。次回のご参加は落ち着いてからで大丈夫ですのでご安心ください。
```

用途: 事例32・33。
禁止: 診断名、治療法、「大丈夫です」、原因の断定、薬・病名の掘り下げ。

**責任・費用に触れられた場合（事例34）は別文**
```
おつらい中ご連絡いただきありがとうございます。まずはお身体を最優先に、医療機関の受診をお願いいたします。お怪我の状況とお手続きについては、オーナーより直接ご連絡いたします。
```
禁止: 保険・治療費・責任の所在に一切触れない。

## T8. 個人情報・未成年者

**他の会員の情報を求められた場合（事例38）**
```
お気持ちはありがたいのですが、会員さまの連絡先をお伝えすることはいたしかねます。ご希望があれば、こちらからその旨をお伝えすることは可能ですので、よろしければお申しつけください。
```
禁止: 在籍の有無、来館の有無、氏名の確認。

**子ども本人からの連絡（事例36）**
```
ご連絡ありがとうございます。お問い合わせいただけて嬉しいです。お手続きは保護者の方とご一緒にお願いしておりますので、おうちの方から一度ご連絡をいただけますでしょうか😊
```
禁止: 住所・学校名・連絡先の聴取、保護者に無断で来館を促すこと。

## T9. クレーム・人間関係（反論しない）

```
{不快な思いへの謝意を1文}。{FLATUPの姿勢を1文}。状況を確認したうえでオーナーより直接ご連絡いたしますので、少しお時間をいただけますでしょうか。
```

用途: 事例37・40・41・43・44・45・46・47。
使える姿勢の一文:
```
FLATUPでは、すべての会員様が安心して通える環境を第一にしております。
```
```
FLATUPは怒鳴らない、威圧しないことを何よりも大切にしています。
```
禁止: スタッフや他会員の弁護、意図の代弁、「気にしすぎ」、会員側に原因を置く表現、口止め、金銭との引き換えの示唆。

## T10. 法的な言葉が出た場合（窓口を閉じる）

```
ご連絡ありがとうございます。ご対応はオーナーが承ります。こちらのトークでのご回答は控えさせていただき、あらためて責任者よりご連絡いたしますので、少々お待ちください。
```

用途: 事例48・49・50。
禁止: 法的見解、規約の正当性の主張、相談を止めようとすること、挑発への反応、謝罪や非の認否。
併せて: **やりとりを削除・編集しない**（記録の保全）。

## 送信前チェック（JIN用・15秒）

1. 日時・金額・返金・退会成立を**確定していない**か。
2. 正本にない数字を書いていないか（特にレディースは土曜14:30、キッズは18:00〜19:00）。
3. 未確定事項（休会費・ビジターの単位・カードキー実費・引落日）を断定していないか。
4. 記号やマークダウンが混じっていないか。3文・200文字以内か。
5. 医療・法的な評価をしていないか。
6. 他の会員の情報に触れていないか。
7. 冷たく突き放していないか（規定より先に受け止めがあるか）。
