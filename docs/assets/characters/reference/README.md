## ⚠️ これらは「公開素材」ではない

**設計を読み取るための参考であって、そのまま広告や投稿に使うものではない。** 理由:

- 実在ブランドのロゴ・商標に酷似した意匠（スポーツメーカーのマーク、飲料ブランド風のステッカー柄）が
  ウェアに写り込んでいる
- メルティにはタトゥーが描かれている（キッズ・保護者向けの訴求では外す方針）

公開用の**基準画像**は、これらの要素を外したクリーン版を別途生成して
[../README.md](../README.md) の規則で `masaki.png` / `melty.png` として置く。

## 使い方

- 新しいカットを作るとき、バイブルの英語ブロックで足りなければここを見て特徴を補う
- **プロンプトに他社ブランド名を書かない**。ウェアは「FLAT UP GYM」表記か無地・オリジナル柄にする
