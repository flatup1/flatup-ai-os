# キャラクター基準画像

シリーズ全話で顔・服装をブレさせないための**基準画像**を置く場所。
ここに置いた画像が、そのキャラの「正解の姿」になる。

## 命名規則

```
docs/assets/characters/<キャラ名ローマ字>.png
```

例: `masaki.png` / `melty.png` / `tsumu.png` / `riku.png`

- 1キャラ1枚。**差し替えるときは同じファイル名で上書き**する（参照が切れないように）
- 縦9:16・1枚に1キャラ・全身が入っているものを選ぶ
- 背景はジムの実景（白い床・緑マット・観葉植物）に寄せる

## 登録の手順

1. `🖼️ 画像を1枚つくる` ワークフローで候補を4枚作る
2. **1枚選ぶ**（下のチェックリストを満たすもの）
3. このフォルダに `<キャラ名>.png` として置く
4. [flatup_animation_bible.md](../../flatup_animation_bible.md) の該当キャラの「姿」欄と
   食い違いがないか確認し、違えば記述側を実物に合わせて直す

## 選ぶときのチェックリスト

- [ ] バイブルの「姿」の記述と一致しているか（髪・目・服・装備）
- [ ] **他社ブランドのロゴ・商標が写っていないか**（ウェア・シューズ・小物）
- [ ] 手・指・足が破綻していないか（AI生成で崩れやすい箇所）
- [ ] 表情が怖くないか。子どもと保護者が安心できる顔か
- [ ] 実在の会員・スタッフの顔に似すぎていないか

## 使い方（以後の生成）

基準画像が決まったら、以後のカット生成では**この画像を参照**して同じ人物を出す。

- 画像から動画: `npm run anime:ep1:video`（`output/clips_src/` の画像を I2V する）
- 新しいポーズの画像: バイブルの英語ブロックを使い、技・シーンだけ差し替える

> ⚠️ 生成物は `output/` に出るが、そちらは一時ファイル。**正式な基準画像はこのフォルダに置く**。
