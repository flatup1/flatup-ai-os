# Mac でのつくり方（ワンタップ）

ターミナルのコマンドを覚える必要はありません。**ファイルをダブルクリックするだけ**です。

---

## はじめかた

Finder で `flatup-ai-os` フォルダを開き、

```
scripts / movie.command
```

を**ダブルクリック**。メニューが出ます。

> 初回だけ「開発元を確認できないため開けません」と出ることがあります。
> そのときは `movie.command` を**右クリック →「開く」**→「開く」を選んでください。以後は普通にダブルクリックで開きます。

初回は必要なものを自動で用意します（1分ほど）。APIキーが未設定なら、その場で聞かれます。
**キーを入れずに進むこともできます**（生成はされず、内容の確認だけ。料金ゼロ）。

---

## メニュー

```
── Day 1  キャラを決める ────────────────
 1) 設定画をつくる（12種 × 2枚）
 2) 採用した設定画を登録する          ← 選ぶだけ。名前は自動

── Day 2  シーンの絵をつくる ────────────
 3) シーン画をぜんぶつくる（12種 × 2枚）
 4) シーンを選んでつくり直す          ← シナリオごと
 5) 採用したシーン画を登録する

── Day 3  編集する ──────────────────────
 6) 編集台本と字幕(.srt)を書き出す     ← APIもネットも不要

── Day 4  動かす ────────────────────────
 7) 動画4カットをつくる

── そのほか ─────────────────────────────
 8) 出力フォルダを開く
 9) 全部チェックする（テスト）
 0) 終了
```

---

## 進める順番

**この順番でないと、キャラの見た目が崩れます。**

| | やること | メニュー | なぜ |
|---|---|---|---|
| 1 | 設定画をつくる | `1` | ここで決めた顔が、以降ずっと使われる |
| 2 | **採用する** | `2` | ★採用画像を以降すべてに自動で添付する。ここを飛ばすとキャラがバラバラになる |
| 3 | シーン画をつくる | `3` | 採用済みの設定画が毎回添付される |
| 4 | **採用する** | `5` | 動画の起点になる。名前も自動でそろう |
| 5 | 編集台本を出す | `6` | 字幕(.srt)と秒数表。CapCutへ |
| 6 | 動画にする | `7` | 4カットだけ動かす |

メニュー `2` と `5` は、**2枚並べて「1か2か」を聞かれるだけ**です。
Mac なら画像がプレビューで自動的に開きます。選ぶと、正しい場所へ正しい名前で保存されます。

> 迷ったら `s` でとばせます。あとからやり直せます。

---

## シナリオごとに作り直す（メニュー `4`）

気に入らないシーンだけ狙って作り直せます。

```
 1) C1   Scene1 グローブの目覚め
 2) C2   Scene2 夜の全景
 3) C3   Scene3 秘密の会議
 4) C4   Scene4 昼の回想・強い子
 5) C5a  Scene5 母の後ろに隠れる
 6) C5b  Scene5 先生が目線を合わせる
 7) C5c  Scene5 手元クローズアップ ★最重要
 8) C5d  Scene5 一歩前へ
 9) C5e  Scene5 はじめてのミット
10) C5f  Scene5 母の表情
11) C6   Scene6 決定の瞬間
12) C7   Scene7 朝
```

番号を選ぶと、何枚つくるか聞かれます（1〜3枚。既定2枚）。
作り直したら、メニュー `5` でもう一度採用してください。

## 料金の目安

画像は1枚あたり数円です。既定の2テイクなら

| | 枚数 | 目安 |
|---|---|---|
| Day 1 設定画 | 24枚 | 数十円 |
| Day 2 シーン画 | 24枚 | 数十円 |
| Day 4 動画 | 8本 | 数百円 |

**APIキーを入れなければ料金は一切かかりません**（内容の確認だけ動きます）。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「開発元を確認できない」 | ファイルを右クリック →「開く」 |
| `Node.js が入っていません` | https://nodejs.org からインストール |
| `403 Host not in allowlist` | ネットワーク制限。Macのターミナルから直接実行すれば通ります |
| キャラの顔がバラバラ | 採用（メニュー `2`）を飛ばしている。もう一度 `1` → `2` から |
| 動画で「起点の静止画がありません」 | メニュー `5` で C1 / C5c / C5d / C7 を採用する |

## ターミナルで直接やる場合

```bash
npm run movie -- list                          # ショット一覧
npm run movie -- refs                          # Day1 設定画
npm run movie:adopt -- refs                    # 採用
npm run movie -- scenes                        # Day2 シーン画
npm run movie -- scenes --only C5c --takes 3   # 1シーンだけ作り直す
npm run movie:adopt -- scenes                  # 採用
npm run movie -- edl                           # 編集台本＋字幕
npm run movie -- cuts                          # Day4 動画
```
