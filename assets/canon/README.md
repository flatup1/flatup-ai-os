## 絵柄（全キャラ共通）

高品質3Dフィギュア風のストーリーライズド3Dアニメ。ちび寄りの丸い体型、
大きくつやのある濃い瞳＋ハイライト、やわらかいほお染め、つやのある肌。
**明るく均一な室内光**（暗く重い映画照明にしない）。

## キャラクター（姿の確定）

### マサキ（19歳・キックボクシングインストラクター）
約5頭身。ボリュームのある黒い逆立った髪＋サイドは短くフェード。
太い眉、大きな焦げ茶の瞳、開いた笑顔。黒の「FLAT UP GYM」タンクトップ
（またはパーカー）、ムエタイショーツ、**左手首に黒いデジタル腕時計**、裸足。

### メルティ（28歳・女性インストラクター）
約5頭身。明るいブラウンのショートボブ（外ハネ気味・無造作）。
**赤いヘッドバンド（最重要の識別子。全カットで必ず着ける）**。
太めの眉、大きな焦げ茶の瞳、ほお染め、自信のある明るい笑顔。
黒のノースリーブ／タンクトップ（ピンクのハート型ロゴ入り）。
**ピンクのハンドラップ、またはピンクの FLAT UP GYM グローブ**。
ステッカー柄のカラフルなムエタイショーツ。裸足。
実戦カットではピンク／黒のレガース（すね当て）を着ける。

### キッズ
約3頭身。全員違う髪型・服。裸足。FLAT UP GYM のムエタイショーツあり。

## ジムの2エリア（描き分ける）

**ジムA（クラス・レッスンの部屋）**: 継ぎ目のないオフホワイトの床 /
淡いグリーンのパッド壁 / 白トラのイラスト入りトロピカル植物の壁画 /
垂れ下がるアイビーと鉢植え / 鏡張りの壁 / 天井のライン照明 /
くすみピンクのカーテン / **赤いLEDの壁掛けタイマー**。
→ 第0話「閉館後のFLATUP」の舞台はこちら。

**ジムB（サンドバッグ・器具エリア）**: 白い壁 / 天井から吊るした
**黄色とピンクの「FLAT UP GYM」サンドバッグ** / 壁一面のグローブとミット /
棚に並ぶヘッドギア / 鉢植えとアイビー / 虎のイラストの「FLAT UP GYM」バナー。
→ 練習風景・スパーリングのカットはこちら。

> 壁掛けタイマー（ジムA）は、キャラクター「タイマー」の実物モデル。同じ赤LED表示にする。

## 使い方

生成時はこのフォルダの画像を**毎回添付**する。`npm run movie` は
`assets/movie/ep0/refs/` を自動添付するので、実制作前にコピーしておく:

```bash
# 第0話（ジムA・道具視点）に必要なぶんだけコピーする
cp assets/canon/masaki_*.jpg assets/movie/ep0/refs/
```

（`assets/movie/` は .gitignore 対象＝作業用。`assets/canon/` はコミットする正本）
