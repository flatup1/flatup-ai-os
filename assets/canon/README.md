## ここから読み取る確定事項

**絵柄**: 高品質3Dフィギュア風のストーリーライズド3Dアニメ。ちび寄りの丸い体型、
大きくつやのある濃い瞳＋ハイライト、やわらかいほお染め、つやのある肌。
**明るく均一な室内光**（暗く重い映画照明にしない）。

**マサキ（19歳・指導役）**: 約5頭身。ボリュームのある黒い逆立った髪＋サイドは短くフェード。
太い眉、大きな焦げ茶の瞳、開いた笑顔。黒の「FLAT UP GYM」タンクトップ（またはパーカー）、
ムエタイショーツ、**左手首に黒いデジタル腕時計**、裸足。

**キッズ**: 約3頭身。全員違う髪型・服。裸足。FLAT UP GYM のムエタイショーツあり。

**ジム内装**: 継ぎ目のないオフホワイトの床 / 淡いグリーンのパッド壁 /
白トラのイラスト入りトロピカル植物の壁画 / 垂れ下がるアイビーと鉢植え /
鏡張りの壁 / 天井のライン照明 / くすみピンクのカーテン / **赤いLEDの壁掛けタイマー**。

> 壁掛けタイマーは、キャラクター「タイマー」の実物モデル。同じ赤LED表示にする。

## 使い方

生成時はこのフォルダの画像を**毎回添付**する。`npm run movie` は
`assets/movie/ep0/refs/` を自動添付するので、実制作前にコピーしておく:

```bash
cp assets/canon/*.jpg assets/movie/ep0/refs/
```

（`assets/movie/` は .gitignore 対象＝作業用。`assets/canon/` はコミットする正本）
