## 絵柄（全キャラ共通）

高品質3Dフィギュア風のストーリーライズド3Dアニメ。ちび寄りの丸い体型、
大きくつやのある濃い瞳＋ハイライト、やわらかいほお染め、つやのある肌。
**明るく均一な室内光**（暗く重い映画照明にしない）。

## ⚠️ 画像より優先される訂正（JIN確定 2026-07-29）

**タトゥーは描かない。**
`melty_stance.jpg` と `melty_sparring_bagroom.jpg` のメルティには腕・脚に小さな
タトゥーが写っているが、**これは不採用**。入会ルール（`src/data/rules.md`
「タトゥー露出は禁止」）と揃えるため、以後どのキャラにも一切描かない。

> このフォルダは原則「画像が文章に勝つ」が、**タトゥーだけは例外**。
> 画像に写っていても再現しない。プロンプトには必ず `no tattoos` を入れる。

**道具たちの瞳は、コンセプト画の描き方を採用しない。**
`tools_night_concept.jpg` の道具は西洋カートゥーン調（白目が大きく黒目が小さい）だが、
**マサキ・メルティと同じアニメ調（大きな濃い瞳＋ハイライト）に統一する**（JIN確定 2026-07-29）。
この画像から採るのは**構成・色・キャラの並び**まで。

## 使い方

生成時はこのフォルダの画像を**毎回添付**する。`npm run movie` は
`assets/movie/ep0/refs/` を自動添付するので、実制作前にコピーしておく:

```bash
# 第0話（ジムA・道具視点）に必要なぶんだけコピーする
cp assets/canon/masaki_*.jpg assets/movie/ep0/refs/
```

（`assets/movie/` は .gitignore 対象＝作業用。`assets/canon/` はコミットする正本）
